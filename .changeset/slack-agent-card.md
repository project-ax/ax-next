An agent's Slack settings are now one card with three states: not in Slack, waiting, and live. Add to Slack is the one button, and it asks an admin to approve by default (people who can install Slack apps themselves have a quiet link for that). Rename, Change picture, Remove from Slack and each channel's memory setting live in ⋯ menus. The card only mentions a problem when something is wrong, and then gives you one thing to do. The plumbing words (approver, claim, rebuild, configuration token) stay in Admin › Slack, where the people who need them are.
