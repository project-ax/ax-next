# AX design assets

Exported from the supplied [AX Figma file](https://www.figma.com/design/yDka46zOpwgipUxTBWiXuo/?node-id=24-20), light frame `24:36` and dark frame `31:9`, on October 8, 2026. SVG exports are stored unchanged.

- `ax-mark-light.svg`, `ax-mark-dark.svg`: 27px sidebar/header mark.
- `ax-mark-small-light.svg`, `ax-mark-small-dark.svg`: 18px composer mark.
- `pearl-orb.svg`: 138px export including shadow, framing a 92px visible orb.

`AxDesignMark` selects the resolved theme variant. All artwork is decorative; accessible names belong to the surrounding product controls and text. Operator branding continues to override the default brand mark.

Inter is self-hosted under `public/fonts`, with its OFL license. Theme tokens and component usage are documented in the root `DESIGN.md`.
