**Correction to TASK-505's row on `hydrateAgentTier` (2026-09-26, TASK-513).**
The TASK-505 context shard is right that hydrate is O(N) round-trips. The card
built from it then inferred the steady-state cost was "bounded and small" because
bootstrap writes nothing after turn 1. MEASURED false: reads, not writes, carry
the cost. ~80 ms per `workspace:read` on the git-server backend on loopback (each
one a fetch against the storage server), linear in the size of `memory/**`:
100 docs = 8.6 s of blocking chat:start time, 300 docs = 25 s. Since TASK-513,
chat:start reads only the 4 bootstrap seed files, and pinned reads skip the fetch.
**Lesson: "writes nothing" is not "costs nothing" — cost where the I/O is.**
