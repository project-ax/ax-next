# TASK-995 — the git workspace tier is gone (context)

Deleted in TASK-995: `packages/core/src/workspace-apply-facade.ts`, `packages/core/src/workspace-policy.ts`, `packages/core/src/__tests__/workspace-return-schemas.test.ts`, `packages/ipc-core/src/handlers/workspace-commit-notify.ts`, `packages/ipc-core/src/handlers/__tests__/workspace-commit-notify.test.ts`

- 2026-10-31 — As built: there is no git workspace tier. The `workspace:*` hooks (pre-apply, applied, apply, read, list, diff), the commit-notify IPC action, governed paths and save-refused are deleted. Four tiers remain: the files home (user files, `AX_USERFILES_ROOT`), the scratch root (`AX_EPHEMERAL_ROOT`, `/tmp` on k8s, with `uploads/` and `transcripts/`), the runner HOME, and the DB. The presets load `@ax/workspace-filestore` / `@ax/workspace-localdir` instead. Rows in the archives that describe the old tier are history; read them that way.
- 2026-10-31 — Attachments are ID-based. The attachment block in a user message carries a stored file ID (one block shape for uploads and artifact chips); download is by ID; chips render from stored blocks. The old text-with-path form survives only as a legacy reader.
