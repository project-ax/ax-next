- 2026-11-06 — Chart.js resolves a function as a scriptable option only at the TOP level of an option. Inside a per-point array (`backgroundColor: data.map(() => fn)`) the entries are not called, the bar color resolves to undefined, and the canvas paints the default BLACK. The frame runtime's `ax.chartColor(name)` returns such a function (and ignores any second "alpha" argument), so the natural model idiom of highlighting one bar with a per-point array draws black bars in both themes. Found on the first claude-sdk walk; a frame-runtime fix needs a test that renders a per-point array of `ax.chartColor` values.
