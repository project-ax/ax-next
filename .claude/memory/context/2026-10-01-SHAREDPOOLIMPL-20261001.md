Current session has read-only Git metadata, no GKE network access, and no Docker socket or local listener access; new prototype changes are uncommitted.
- Shared-pool path is now opt-in and wired from Helm env through preset-k8s to the real sandbox plugin and HookBus canary. It creates hash-specific SandboxTemplate/WarmPool classes for the shipped Claude SDK and AI SDK binaries, with no agent/session credentials in templates and no claim.env. Default one standby per class is two total, independent of registered agent count. Service-sidecar sessions retain the existing cold path. Configuration changes retire old standby classes without deleting claim-owned sessions.
- Both runner main functions await a common single-use bootstrap gate before runner state/IPC/model work. It validates private mode/owner, instance UID, expiry, byte bounds and an env capability allowlist, removes credentials before acceptance, and publishes an identity-only receipt. commitTrace now reads its flag at call time because standby imports happen before assignment.
- Node helper is compiled into sandbox-k8s and reached by an image-packaged resolver entrypoint and a chart DaemonSet. Dedicated-CA mTLS, node/claim/Sandbox/Pod UID checks, optimistic finalizer patches, held directory descriptors, fixed mount argv, a node-private secret-free ledger and process lock protect attachment and recovery. Cleanup waits for terminated containers, syncs, lazily detaches (the earlier EBUSY regression), checks mountinfo, then clears only its own finalizers. Kernel/NFS/finalizer ordering still requires real GKE acceptance; Linux FD tests are skipped on macOS.
- The original authorized owner is stamped internally before the pool adapter validates mount-resolver output; resolver output cannot select a sibling agent. Memory's unchanged volumeAgentKey algorithm is now one pure shared function in sandbox-protocol, re-exported by memory, so the helper and resolver do not duplicate it. No service-hook or IPC signatures changed.
- Shared runners have a dedicated label excluding them from cold NFS egress; direct NFS client access could otherwise bypass per-agent mounts. Helper API reach is controller-only. Host retains no Pod patch, exec, Secret-read, or cluster permissions. Helper privileges can reach kubelet Pod storage, including other Pods' mounted secrets; its compromise has node-wide consequences, explicitly documented.
