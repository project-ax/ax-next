# Context — TASK-398 measurements (2026-09-28, OrbStack 29.4.0, 14 cores)

Sampled `docker ps -a --filter ancestor=postgres:16-alpine` every 3s. Liveness was checked first with `docker version`.

| Run | Peak pg containers | Peak `health: starting` | Failed test files | Orphans 60s after exit |

| main, 3 concurrent runs of the 20 postgres packages | 87 | 79 | 17 (all "Hook timed out in 60000ms") | 0 |
| slots=4, 1 full gate | 7 | 4 | 0 (247s) | 0 |

Readings:
- Ryuk reaped every run, including the starved one. Orphans did NOT reproduce from starvation alone on this host. The card's 19-hour orphans need another cause (killed runners, or a wedged daemon).
- The bound works: peak `health: starting` equals the slot count. But at 4 slots with a 40s wait, 3x load turns 17 hook timeouts into about 100 named give-ups. That is a worse pass rate, just louder. The slot count and wait still need tuning before this ships.
- The daemon wedged under slots=8 at 3x load, but not under the unbounded 87-container run. One sample, so no causal claim.
- vitest hides `console.warn` from passing files, so the "waiting for a slot" line only shows up when a file fails.

## CORRECTION (23:50, same day): the "wedge" under slots=8 was the Mac going to sleep, not load

`pmset -g log`: **22:48:44 Entering Sleep state due to 'Clamshell Sleep'** — the second the slots=8
stress run started — followed by DarkWake/Maintenance-Sleep cycles (22:49, 22:54, 22:55, 22:58, 23:03
for 819s, 23:30 'Dark Wake Thermal Emergency' for 919s). `ioreg AppleClamshellState = Yes`. The
follow-up full gate then showed 22 hook timeouts and one test that "took" 918319ms — exactly the
919s sleep. So:

- "3x stress wedges the daemon" is NOT established — the one sample coincides with host sleep.
- Before diagnosing a Docker "wedge" on this laptop, read `pmset -g log | grep -E ' (Sleep|DarkWake|Wake) '`
  for the window. A sleeping host presents exactly like a wedged daemon: `docker version` times out,
  hooks time out, nothing is reaped.
- The four clean rows above (before 22:48:44) are unaffected.
