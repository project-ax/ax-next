# GKE Agent Sandbox lifecycle backend

- Agent Sandbox is an opt-in internal lifecycle backend for @ax/sandbox-k8s; the Pod backend remains the default. Fresh Sandbox resources preserve the existing runner/session hooks and receive namespaced create/get/list/delete permissions only. No templates, claims, warm pools, router or snapshots are introduced.
- Both CRD versions are supported. Managed GKE on 1.36.4-gke.1247000 serves v1beta1; its gVisor node has sandbox.gke.io/runtime=gvisor. GKE admission requires explicit node placement, no service-account token, non-root execution, dropped capabilities, and CPU/memory limits on ALL containers including sdk-scaffold. The live dry run caught the missing scaffold limits; a regression was observed RED, then the bounds were added and all 311 sandbox-k8s tests passed.
- Writable NFS ownership is prepared in a separate fixed-command gVisor Pod with only CAP_CHOWN, the agent subtree, and no session/proxy credentials. Read-only memory and native service sidecars remain in the non-root Sandbox. Both the parent and Pod have bounded lifetimes. Cancellation revokes the session before foreground, UID-constrained parent deletion; backing-Pod disappearance/replacement ends the session instead of adopting the controller's replacement.
- Isolated managed-controller fixture checks passed real hook launch, GKE admission, gVisor kernel observation, UID 1000, absence of a service-account token, cancellation/revocation/parent-child cleanup and Pod-death cleanup. Deny-all NetworkPolicy blocked a TCP connection. Fixture ready times were 4.4 s and 3.3 s on an existing node, not chat latency. Temporary namespace was removed. No persistent mounts, real chat/model call, AX proxy allowance, cross-agent isolation or host restart was exercised by that fixture.
- Vinay explicitly authorized bringing in latest main and deploying to the live ax-next release. Main fast-forwarded to b9edba46 (#832 MCP OAuth host discovery); the sandbox changes applied without overlap. Deployment work uses the isolated codex/gke-agent-sandbox branch/worktree. Preserve existing Helm values and Secret data; verify no live runners before host restart; apply the Agent Sandbox values overlay last. Deployment result will be recorded separately after rollout.
