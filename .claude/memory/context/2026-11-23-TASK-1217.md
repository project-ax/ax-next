- `2026-11-23` — **Measured on CLI 2.1.119 (M3):** the CLI watches a settings dir only if its `settings.json` existed at CLI start (even `{}`); then a mid-session plant hot-reloads (planted `UserPromptSubmit`/`PreToolUse` hooks fire, Bash sees the planted env). With no settings file at start, a mid-session plant changes nothing (M2). A NEW CLI process on a dir the previous session's shell wrote runs its hooks and env (M1).
- `2026-11-23` — **Skills hot reload is live (M5).** The CLI watches `$CLAUDE_CONFIG_DIR/skills`, `…/commands` and `<cwd>/.claude/skills`. After `chmod -R u+w` on the 0555 projection, an edited SKILL.md body is what `Skill(name)` launches and a planted folder's description reaches the model's listing. The runner's name allowlist still refuses a planted name, but not a tampered body of an allowed one.
- `2026-11-23` — **Instruction files (M6):** `$CLAUDE_CONFIG_DIR/CLAUDE.md`, `rules/*.md` and auto-memory `MEMORY.md` load at session start and again after compaction; a mid-session write is NOT re-read per request or turn. `CLAUDE_CODE_DISABLE_CLAUDE_MDS=1` removes the CLI's start-of-session/after-compaction list (every source); it does NOT cover every CLAUDE.md loading path (e.g. nested files picked up when reading a subdirectory).
- `2026-11-23` — **Background tasks (M7):** `run_in_background` AND any Bash command that outlives its `timeout` (auto-backgrounded, unless it starts with `sleep`) wake the model with an unprompted `<task-notification>` turn. `CLAUDE_CODE_DISABLE_BACKGROUND_TASKS=1` removes the schema field, refuses a call that sends it, and kills the timeout case (exit 143).
- `2026-11-23` — **A person's text (M8):** a message starting with `/` is a CLI command (`/update-config`, `/simplify` expand with no `Skill` call; `/clear` makes no model call and switches session id; unknown `/x` is answered by the CLI). A leading U+200B makes it plain text; a leading space does not (the CLI `trim()`s).
- `2026-11-23` — **The four controls:** (1) `assertConfigDirFresh` refuses to boot on a config dir an earlier session could have written (config dirs are fresh per session in every sandbox, so no cost); (2) `ConfigChange` SDK hook blocks every mid-session reload, fail-closed (its log call is wrapped, since a throwing hook lets the CLI reload); (3) env floors `CLAUDE_CODE_DISABLE_CLAUDE_MDS=1` and `CLAUDE_CODE_DISABLE_BACKGROUND_TASKS=1`; (4) `keepSlashAsText` plus a runner refusal of an AX skill whose name the CLI answers to (the collision e2e marker is `Launch Three Review Agents in Parallel`).
