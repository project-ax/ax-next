# Meta — TASK-576

- **A `run_in_background` `sleep` does not make me wait.** I issued ~10 back-to-back background sleeps "to yield" while subagents worked and believed ~40 minutes had passed; the wall clock said 2. The tool returns immediately and the completions arrive later as a pile of notifications. To actually wait on a subagent, run a FOREGROUND until-loop (timeout ≤600000) on its transcript (`~/.claude/projects/<proj>/<session>/subagents/agent-<id>.jsonl`) for `"stop_reason":"end_turn"` — and check `date` before believing any elapsed-time estimate.
- **Parallel builders in one worktree work if none of them commits.** Four subagents (purge package, backends, facts count, migration, chart) ran concurrently in the same tree with a "no git writes, touch only these paths" brief; I committed each slice by path. The one cross-slice breakage (a preset test pinning the exact `workspace:*` hook list) was reported, not silently fixed, because it was outside the builder's path list.
