# TASK-435 — meta

## A subagent given "run the suite" will run the whole suite, repeatedly

Dispatched one implementation subagent with the instruction to verify via
`npx tsc --noEmit` and `npx vitest run` in `packages/channel-web`. It produced a
correct, well-commented diff in roughly the first 25 minutes and then spent
**another ~2 hours** re-running the package suite — which boots Postgres
testcontainers — after each one-line fixture fix. The file set in the worktree
was stable the whole time, so from outside it looked identical to a hang.

Two things I would do differently, both cheap:

- **Name the verification command exactly, and cap it.** "Run `npx tsc --noEmit`
  and `npx vitest run <the specific paths your change touches>`; do not run the
  package suite, I will" would have saved most of it. A subagent has no way to
  know that the orchestrator is going to run the full gate anyway.
- **`TaskStop` does not work on a subagent you dispatched** — it answers
  `Task <id> is owned by <id>; agent <you> cannot stop it`. The only lever is
  `SendMessage`, and messages drain at the agent's **next tool round**, so a
  subagent inside a 10-minute `vitest` call does not see your stop for ten
  minutes. Budget for that: two stop messages landed ~25 minutes apart before it
  returned.

What worked: the diff was already committable when I took over. Reading the diff
myself and committing it as a checkpoint, then finishing the verification in my
own context, cost about 15 minutes. I should have done that an hour earlier —
the signal to act on was "the file set has not changed in 40 minutes", not "the
agent has not returned".

## The bash tool refuses nested shells that mention git, in a worktree

In a worktree-isolated agent, `/bin/bash -c '…git…'` and heredoc-plus-`git`
compound commands are both refused as "too complex to verify that it stays
inside the worktree". The yolo-ship mutation-restore blocks are written as
multi-line bash and have to be run as separate plain commands instead — the
gates still hold, they just cost one Bash call each. Writing files goes through
the Write tool rather than a heredoc.
