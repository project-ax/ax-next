# TASK-519 — mistakes to avoid (2026-09-25)

- **Ran the full local gate while the new files were still UNTRACKED, reported it green, and CI failed.** `scripts/__tests__/no-deployment-specifics-committed.test.js` scans `git ls-files` under `deploy/` and `docs/`, so untracked files are invisible to it — the kind NFS assets' `10.96.200.49` / `10.244.0.1` / `10.96.0.0` passed locally and failed CI. **Fix:** commit (or at least `git add`) new files BEFORE the gate, or re-run `pnpm test:scripts` after committing. Any guard built on `git ls-files` / `git grep` has the same blind spot.
- The legitimate fix for a kind-default private address is the guard's `EXAMPLE_ADDRESSES` allowlist (its test: "would the same string be in a stranger's fork?") — kind's default ranges and a ClusterIP the repo pins pass it; a real VPC address never does.
