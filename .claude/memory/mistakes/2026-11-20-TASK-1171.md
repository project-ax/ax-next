| 2026-11-20 | **Two implementer subagents ran in parallel in ONE worktree on disjoint files. Each was told to stage only explicit paths, and one's staged change still landed in the other's commit.** The channel-web implementer had run `git add` on `AgentSlackBotChanges.tsx` and its test. The channel-slack implementer then ran `git commit` with its own paths staged too, and `git commit` with no pathspec commits the WHOLE index. So commit `3c968cdb0` ("channel-slack: …") carries the channel-web `tabIndex={-1}` fix, and the other agent's own commit hit `index.lock` at the same moment. The content is correct; the subject is wrong. | Disjoint files plus an explicit `git add` is not isolation. A worktree has one index, and staging is shared state. If parallel implementers share a worktree, each must commit with `git commit -- <its paths>` (the pathspec goes on the COMMIT, not just the add), or they run one after the other. The earlier parallel pairs in this card (Tasks 4+5, 6+7) were only lucky with timing. |
