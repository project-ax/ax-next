# TASK-980 — scheduled task tool schema

- A production chat made fourteen unsuccessful routine_create calls, all carrying a webhook object, including its attempted null repair. The host correctly rejected app updates for task kinds. The advertised JSON definition independently offered schedule-or-webhook for every kind, allowing calls the host would never accept. Prior production smoke created the definition through HTTP and exercised reporting, so it did not test model-authored creation through chat and approval.
- Validate model-facing JSON Schema with a real JSON Schema validator as well as the runtime Zod parser. New Ajv regressions observed five failures before the fix: webhook-bearing task creates and incompatible task settings passed the advertised schema. The corrected kind-specific branches require a task schedule and goodWhen, omit/null its webhook, and retain per-fire/no-silence constraints. Repeat keeps schedule-only, webhook-only and both methods. Defaults, legacy parsing, authority and persisted data are unchanged. Ajv8.20.0 is a pinned test-only dependency already present transitively; no new transitive packages were introduced.
