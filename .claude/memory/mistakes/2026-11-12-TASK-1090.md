- **2026-11-11: I told the user to hand me Slack tokens with `! export SLACK_CONFIG_TOKEN=…`. That put both tokens in the transcript, and the export didn't even reach my commands** (each Bash call is a fresh shell; `!` runs in its own). **Lesson:** to hand a secret to an agent session, have the user write it to a mode-600 file in the scratchpad *from a separate terminal* (`umask 077; printf … > <scratchpad>/x.env`) and `set -a; . file` per command. Never `!`, and never paste.
- **2026-11-12: Checking "does the old Slack refresh token still work?" by calling `tooling.tokens.rotate` with it MINTED a live credential I didn't capture** (twice: once after a rotation, once after `auth.revoke`). **Lesson:** for a credential, "is it still valid?" is never a read. A refresh/rotate probe issues a new token. Capture the result (and revoke it at once), or ask the person to check the provider's UI instead. Slack can't retire configuration refresh tokens through the API, so an uncaptured one has to be revoked on the api.slack.com/apps page.
- **2026-11-12: I called app creation "fully automatic" while the user had just clicked Allow on two install screens.** The accurate claim was "no step beyond the install consent". **Lesson:** when a flow has a consent screen, count it as a human step in every summary.
