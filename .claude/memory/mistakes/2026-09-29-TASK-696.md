| 2026-09-29 | Ran the CLAUDE.md memory-shard snippet verbatim in the Bash tool: `path=$(scripts/memory-write-target.sh --shard decisions TASK-696)`. The Bash tool runs zsh, where lowercase `path` is TIED to `PATH`; assigning a string to it emptied the command search path and the next line failed with `command not found: dirname` / `mkdir`. | Never name a shell variable `path` (or `PATH`-tied `fpath`, `cdpath`, `manpath`) in a snippet that may run under zsh; use `SHARD=` (this repo's own CLAUDE.md snippet uses `path=`, which is why it bit). Run the command with the output printed first, then create the directory with a literal path. |
