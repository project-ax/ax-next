# TASK-1170 — Slack DMs for bot requests (mistakes)

- 2026-11-20 — **`auth:list-admins` / `auth:find-user-by-email` see only VERIFIED emails, and the setup-wizard admin is stored unverified** until they sign in with Google/GitHub. On a deployment whose only admin never did, nobody is DMed about a bot request and Slack's Decline refuses them. By design (the card asked for verified only), but expect it on a walk before calling the DMs broken.
- 2026-11-20 — **COPY may never name the product**: `copy.test.ts` fails any line matching `\bAX\b` (white-labeled). A card's quoted copy ("An AX admin declined…") is a draft, not a spec.
- 2026-11-20 — **A plan's Pick<> on a dependency can be impossible**: `admitSender` takes the whole `SlackApi`, so any module that calls it takes `api: SlackApi` too. Check the helper's signature before narrowing a dep in a plan.
