- **A "does not re-read when the value is unchanged" test for a React effect cannot fail (TASK-707).** If the effect's deps are referentially unchanged, React never re-runs it, so the equality guard inside never executes and the test passes against every guard mutant. Dropping the guard entirely survived the whole TASK-686/707 suite; the guard's only real job was the MOUNT, where the deps-keyed effect runs beside the initial-load effect. Pin it with a mount read count (`toHaveBeenCalledTimes(1)` outside the provider) instead. Mutate the guard before trusting a negative test of this shape.
