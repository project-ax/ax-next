# Mistakes — TASK-1179

| Date | Mistake | Lesson |
|---|---|---|
| 2026-11-20 | **A reviewer ran a stale script from the shared scratchpad and mutated ANOTHER worktree.** Its write of `scratchpad/mutate.sh` was refused by the harness, but its next command ran `scratchpad/mutate.sh` anyway: a leftover TASK-1128 script from the day before, which mutated and restored `channel-slack/src/{migrations,store}.ts` in that card's (merged, idle) worktree and started ~10 Postgres containers. Files came back byte-identical; the reviewer self-reported it. | The session scratchpad is shared across sessions and agents and holds generically named scripts (`mutate.sh`, `mutants.sh`). Name scratch scripts uniquely (task id + purpose) inside a task-scoped dir, and confirm a write landed before running anything by name. A refused write followed by "run it" executes whatever was already there. |
| 2026-11-20 | **A fix that reads a setting "at first use" leaves a window where the source row can vanish first.** TASK-1179 carries the shared-app memory switch into a bot's binding at its first mention; Admin Disconnect (or Disconnect on a moved row) deletes the shared binding before that, and the team's OFF is lost. | When a privacy setting has to follow a resource to a new owner, ask what deletes the source before the copy happens. Copying at the hand-off moment (the bot going live) is the robust shape; copying lazily needs every deleter to know. |
