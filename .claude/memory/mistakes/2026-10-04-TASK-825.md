# TASK-825 mistakes

- `2026-10-04` (TASK-825) — **`producer | grep -q` under `set -o pipefail` is a race, not a check.** `grep -q` exits at the first match and closes the pipe; any later write by the producer dies of SIGPIPE, and pipefail reports the pipeline as FAILED even though the match was found. It only shows when the match is not the last line AND the producer writes in more than one chunk (bash builtins line-buffer stdout, so even one `printf '%s\n' "$multi_line"` is several writes). Use `grep -F… >/dev/null` (reads to EOF) in any pipefail pipeline. Also: a Makefile `.SHELLFLAGS` is IGNORED by macOS make 3.81 — a Makefile behaviour that only CI's GNU make 4 sees will "pass locally" forever; reproduce it in a Linux container (`node:24-bookworm` + `apt-get install make jq`).
