# TASK-1047 — what bit us (mistakes)

- 2026-11-05 — A plan doc that QUOTES a test's token-shaped fixture (`TOKEN: '<24 letters+digits>'` in a `docs/plans/` code block) trips CI `gitleaks` rule `generic-api-key`, while the same literal in the `__tests__/` file it was copied from does not. gitleaks scans every commit in the PR range, so a fix-up commit cannot clear it: the branch had to be rewritten (`git filter-branch --tree-filter` over `merge-base..HEAD`, replacing the literal in the plan only) and force-pushed with lease, which also re-pointed `reviewed-sha`. In plans and PR bodies, write a placeholder (`<RESET-TOKEN-FIXTURE>`) for any secret-shaped fixture, never the value. Never add a `.gitleaksignore` entry for it.
