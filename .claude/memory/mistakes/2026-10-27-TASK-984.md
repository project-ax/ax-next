# TASK-984 — test invocation

- 2026-10-27 — `pnpm --filter @ax/routines test -- <files>` produced `vitest run -- <files>` and unexpectedly selected the whole package, starting many Docker suites. Stopped only that process tree and switched focused runs to `pnpm --filter @ax/routines exec vitest run <files> --maxWorkers=1`. Package selection and Vitest's positional separator are separate traps. Set explicit DOCKER_HOST on every Docker-backed package invocation; a web run without it passed ordinary cases but failed six suite setup hooks, which needed a bounded rerun with the named socket.
