# TASK-1223 (walk, 2026-11-24)

- `helm upgrade --reuse-values` across a chart that adds defaults drops those defaults: `--reuse-values` ignores the new chart's values.yaml. Helm 3.13 has no `--reset-then-reuse-values`. Save `helm get values -o yaml` to a private file and pass it with `-f` after `kind-dev-values.yaml`.
- A fresh worktree has no `deploy/charts/ax-next/charts/` (the vendored postgresql tgz is untracked), so `helm upgrade` fails with "missing in charts/ directory: postgresql". Copy it from the main checkout.
- `kind load` can fail with "no space left on device" while the node reports 20 GB free: the kind node shares the OrbStack VM disk with Docker's images and build cache. Old tagged `ax-next/agent:*` images on the node (`crictl rmi`) and old build cache freed it. `make kind-prune` only removes untagged ones.
- With Docker's containerd store, `kind load` always says "not yet present", and the node's image id differs from `docker inspect`'s. Compare `.info.imageSpec.created` (crictl) with `docker inspect .Created` instead.
- Chromium allows 6 connections per host, and every open workspace tab holds long-lived event streams. Past about three tabs, a new tab's `page.goto` times out. Close finished tabs, or use a second browser context.
- A dev-services walk needs `restart: "no"` on one-shot jobs. Without it the importer makes them sidecars, which restart forever. postgres also needs `PGDATA` in a subdirectory (TASK-1241).
- A walk check about "N live at once" must allow for the idle reaper: a services sandbox is reaped about 5 minutes after its last reply, which frees a slot.
