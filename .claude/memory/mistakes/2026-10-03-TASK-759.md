# TASK-759 — an `optionalCalls` entry is a boot-order edge, not just documentation

- Every `optionalCalls` hook with a present producer is a kernel call-graph edge
  (init order + cycle check), exactly like `calls`. Declaring a runtime-only peer
  (looked up per call with `bus.hasService`) can close a cycle that only forms in one
  preset shape and crash-loop the host while every unit test stays green. Before
  adding an optionalCall, ask "do I need this producer at INIT?" — if not, leave it
  out of the manifest and gate it with `hasService` (chat-orchestrator's convention).
  `presets/{k8s,memory}/src/__tests__/boot-graph.test.ts` now catch the cycle.
- zsh trap: `path=$(…)` clobbers `$PATH` (zsh ties `path` to `PATH`). Use another name.
