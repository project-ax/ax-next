## 2026-10-04 — TASK-816

- **CLAUDE.md's shard snippet `path=$(scripts/memory-write-target.sh --shard …)` breaks the Bash tool shell, which is zsh.** In zsh `path` is tied to `PATH`, so assigning a string to it empties the command search path and every later command in that call fails with `command not found: cat` / `ls` / `head`. Use another name (`shard=$(…)`). Same family as the "brace before `:`" zsh trap.
