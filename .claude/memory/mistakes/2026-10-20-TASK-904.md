# TASK-904 mistakes

- 2026-10-20: `pnpm --filter @ax/<pkg> test -- <file>` does NOT run one file. Under pnpm 10.33 + vitest 5 the `--` is passed through and vitest runs the whole package (a `-t` name filter is dropped too), so a "red" run you meant for one file is the full suite. Three implementers hit it independently from one plan's commands. Use `pnpm --filter @ax/<pkg> test <file>` (no `--`) or `pnpm exec vitest run <file>` from the package directory, and check the file count in the summary line.
