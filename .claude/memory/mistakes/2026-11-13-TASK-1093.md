# TASK-1093 — what bit us (mistakes)

- **2026-11-13: `beforeEach(() => vi.mocked(fn).mockClear())` failed every test in the file with an error from INSIDE the mocked function** (`The "buf1" argument must be an instance of ...`), raised after each test body. `mockClear()` returns the mock, and vitest runs a function returned from `beforeEach` as that test's teardown, so it called `timingSafeEqual()` with no arguments. **Lesson:** give `beforeEach`/`beforeAll` a block body (`() => { ...; }`) whenever the expression returns anything callable. An error naming arguments your code never passed is a teardown, not your code.
- **2026-11-13: I committed a fake Slack bot token in a test with a REAL token's exact shape (`xoxb-<13 digits>-<13 digits>-<24 characters>`).** Gitleaks allowlists `__tests__/` here, so CI says nothing. But GitHub push protection scans every pushed commit, so the shape can block the push even after a later commit changes it. Fixed forward in a `fixup!` commit, because rewriting history was off-limits mid-review. **Lesson:** fake tokens keep Slack's prefix but short digit groups (`xoxb-1111-2222-...`, as `slack-api.test.ts` does). Grep `xox[bpe]-[0-9]{10,13}-` before committing test fixtures.
- **2026-11-13: A "refuses a malformed timestamp" test passed for the wrong reason.** Every malformed value was also hours outside the replay window, so deleting the digit rule broke nothing. A mutation run caught it; review didn't. **Lesson:** make each negative case valid on every OTHER rule (here: spellings that `Number()` reads as exactly now), then delete the rule under test and watch the test fail.
- **2026-11-13: A mutation loop reported nothing for six mutants: zsh passed `vitest run $T` (with `T='a.test.ts b.test.ts'`) as ONE argument, so vitest matched no file and printed no `×` lines.** Silence read like "nothing failed" until I noticed even the summary line was missing. **Lesson:** under the Bash tool's zsh, keep a file list in an array (`T=(a b); vitest run "${T[@]}"`) or split explicitly (`${=T}`), and make each mutant's run print its `Tests` summary, so an empty run can't pass for a clean one.
- **2026-11-13: Playwright MCP's `browser_run_code_unsafe` runs each call in a fresh context.** A `page.route` handler registered in one call can't see a `globalThis` value set in a later call, so "switching the faked state" silently kept serving the old one. **Lesson:** to fake a backend per state, `unrouteAll` and register the route again in the same call, with the state in the closure.
