| 2026-10-05 | **`@ax/credential-proxy` CONNECT target is parsed by `parseConnectTarget` (`src/connect-target.ts`): strict authority-form `reg-name / IPv4 / [IPv6] ":" port`, port REQUIRED, else the existing 400 + `blocked: 'invalid_target'`.** Replaces `target.split(':')` + `parseConnectPort` at the one parse site, so both MITM and bypass paths get it before allowlist/DNS/dial. | Card asked for it; RFC 9110 §9.3.6 says the client MUST send the port. `split(':')` read `host:443:x` as `host:443` and turned `[::1]:443` into host `[`. Pure function = table-testable without sockets. | Keep `split` and add a "no extra colon" check (still no v6); `new URL('http://' + target)` (accepts userinfo, paths, IPv4 shorthands, `%`-decoding — too lenient for a boundary). |
| 2026-10-05 | **A target with no `:port` is now REFUSED (400), reversing TASK-862's "still defaults to 443" pin.** | Card's acceptance lists "missing port" as a reject; RFC 9110 requires the port; the only in-repo emitter (`@ax/credential-proxy-bridge`) forwards the client's `req.url` verbatim, and Node/undici/curl/python all send `host:port`. | Keep the 443 default (lenient on untrusted input for no known client). |
| 2026-10-05 | **Bracketed IPv6 is returned unbracketed AND canonicalized via WHATWG URL host serialization (`[0:0:0:0:0:0:0:1]` → `::1`); zone ids (`%`) and IPvFuture rejected.** | The HTTP forward path already checks the allowlist + private-IP on `URL.hostname` minus brackets, i.e. canonical form. Without canonicalizing, CONNECT would hand `isPrivateIPv6` an uncompressed `0:0:…:1`, which its string-prefix check does NOT recognise as loopback. | Return the literal as written (opens that SSRF gap the moment someone allowlists a long-form literal). |
| 2026-10-05 | **Numeric-looking names must be a dotted-quad IPv4 (`127.1`, `2130706433`, `0x7f000001` refused).** | WHATWG "ends in a number" rule; getaddrinfo/inet_aton would expand them to an IP the allowlist never named. SSRF still checks the resolved IP, so this is defence in depth, not a hole closed. | Accept and rely on the resolved-IP check alone. |
| 2026-10-05 | **Rewrote `isPrivateIPv6` to parse groups (covers ::/96, ::ffff:0:0/96, 64:ff9b::/96, fe80::/10, fc00::/7) in the same PR.** | Opening bracketed v6 on CONNECT + canonicalizing turns `[::ffff:127.0.0.1]` into `::ffff:7f00:1`, which the old prefix check called public. Shipping the grammar without this would add an SSRF spelling to CONNECT (gated only by an allowlist entry). | Separate follow-up card (leaves CONNECT strictly worse for one PR); reject all embedded-v4 IPv6 at parse (HTTP path stays exposed). |
| 2026-10-05 | **Implemented inline, not via per-task subagents.** | ~70-line pure module + one call-site swap + test table; dispatch overhead exceeded the work. | subagent-driven per task. |
