# TASK-492 — decisions

## 2026-09-21 — The `memory_recall` tool renders the LIVE DEM evidence table, not the stale card's

The card sketched `Kind | When | Statement`; the user explicitly chose "match
live DEM", so the heading is `Network | When | Statement` (what
`dem-memory/src/engine/reflect.ts` actually emits) with DEM's four-network tag
map (`world`/`experience` → `FACT`, `observation` → `OBS`, `opinion` → `OPIN`).
`relativeTime`/`utcMidnight`/`monthsBetween`/`plural` are ported
algorithm-unchanged. Deliberate divergences from DEM, each pinned by a test:

- `UNKNOWN` for absent kind — DEM requires `network`; we carry it optionally,
  so a kind-less row renders `UNKNOWN` rather than a fabricated `FACT`.
- Escaping — DEM renders verbatim; every field runs through
  `escapeStatementText` (the shared owner in `render.ts`) so a pipe or newline
  in a stored value cannot forge a row.
- Whitespace normalization — escaping collapses runs of whitespace/newlines
  inside a field where DEM would emit them raw.
- 400-character per-field cap — `escapeStatementText` truncates; DEM does not.

## 2026-09-21 — `tool:register` is a HARD dependency, and the executor rides `tool:execute:`

Same shape `@ax/memory-strata` already uses: `tool:register` sits in
`manifest.calls` (a memory plugin whose tool never catalogued is the
half-wired shape invariant 3 forbids), init is `async` and awaits
`registerMemoryRecall` LAST — after the product hooks exist, since the
executor is a `tool:execute:memory_recall` service over `memory:recall`. No
`mcp-client` dependency; `@ax/tool-dispatcher` provides the catalog.

## 2026-09-21 — The tool payload is exactly `{query, limit}` — refused beyond that

`additionalProperties: false` in the schema AND a runtime whitelist: a
smuggled `ownerUserId`/`agentId`/`provenance`/`kind`/`ids`/`at`/`history`/
`poolSize`/`activeOnly` field throws `invalid-payload` rather than being
honoured or silently dropped. `limit` must be an integer (schema hint AND a
`Number.isInteger` runtime guard); >40 clamps to 40 for direct callers. No
`at`/history field at all — decided-not-built. Engine pool scales as
`Math.min(200, Math.max(40, Math.ceil(limit * 40 / 15)))` (lead-authored: 15 →
the measured 40, 40 → 107).

## 2026-09-21 — `kind` is optional end to end, and nobody invents one

`FactKind = 'world' | 'experience' | 'observation' | 'opinion'` added to
`FactStatementInput`/`FactRecord`; nullable `kind TEXT` on both backends with
additive ALTER migrations (no backfill — legacy rows keep NULL and read back
with the property ABSENT). Extractor `network` maps to `kind` only after
validation; a present-but-unknown network marks the fact unusable (retry once,
then loud failure). `memory:remember` still stores no kind — a human write
carries no classification and none is fabricated.
