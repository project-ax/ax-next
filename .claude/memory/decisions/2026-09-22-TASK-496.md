| 2026-09-22 | Helm `memory.*` fields live under the EXISTING top-level `memory:` key alongside `orchestratorModel`, not a second `memory:` block | Duplicate top-level YAML keys — js-yaml throws, `render.test.ts` red | Second `memory:` block (invalid YAML — caught by render.test.ts) |
