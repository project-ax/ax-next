# Decisions — SIGNINS-8 (agent-owned connector sign-ins, slice 6: routine skip warning)

Shard id `SIGNINS-8` covers slice 6. Spec: `docs/plans/2026-10-07-agent-owned-connector-sign-ins-design.md` §6; plan: `docs/plans/2026-10-07-agent-owned-sign-ins-slice6-plan.md`; ledger: `.superpowers/sdd/2026-10-07-agent-owned-sign-ins-slice6-plan/progress.md`.

| Date | Decision | Rationale | Alternatives |
|------|----------|-----------|--------------|
| 2026-10-08 | **`last_warning` is written inside `recordFire`, in the same SQL statement as the fire row** (a CTE `UPDATE … ; INSERT … RETURNING`). `advance` never touches it. Amended by the final wave: only when `warning` is passed (see the pre-assembly row). | The fire row and the routine's warning can't diverge. Cost if wrong: none. | A separate `setLastWarning` (rejected: two writes that can split). |
| 2026-10-08 | **A routine turn (`ctx.source === 'routine'`) is never routed to a warm session.** Routing retires any live session for the conversation like every other "can't reuse" case (`stale_session_respawn` reason `routine-turn`: bind-session moved first, proxy closed, `session:terminate`) and spawns fresh. Interactive warm routing is unchanged. | A shared routine re-fired inside the keepAlive window reused the warm session, assembled no connectors, fired no `chat:connectors-skipped`, and silently CLEARED the warning. This makes "routines always spawn fresh" true by construction. Cost: shared routines lose warm reuse (one spawn per fire). | Fire the skip event on the warm path too (rejected: a reused session assembles nothing, so there is nothing true to say). |
| 2026-10-08 | **A fire that fails BEFORE turn assembly leaves `last_warning` unchanged.** `RecordFireInput.warning` is optional: `undefined` = don't touch (the fire row's warning is null), `null` = clear, a string = set. tick/fire-now's pre-dispatch failures (resolve forbidden, conversation create) omit it. | Such a fire says nothing about which connectors a run would go without. Cost if wrong: a stale warning survives one failed fire. | Clear on every fire (rejected: a refused fire would erase a true warning). |
| 2026-10-08 | **Which settled fires count as "reached assembly"** (`fire.ts` `settleWithoutTurn`): the pending entry existed and the invoke was dispatched → write the warning (sentence or null), EXCEPT when the invoke threw (a dispatch error; agent:invoke otherwise always answers an outcome) or answered `terminated` with a front-gate reason — `chat:start:<reason>` (veto) or `agent-resolve:<code>`. Other terminated reasons and the turn-end grace backstop write. | Reconciles the ruling's "pending entry + dispatched" with its explicit list of pre-assembly failures (chat:start veto, dispatch error). Stash-touched isn't usable as the signal: a clean assembly never touches it. Cost if wrong: an unclassified pre-assembly config error (e.g. `proxy-not-loaded`) clears a stale warning — the cheaper mistake. | A new "assembled" hook event (rejected: hook-surface change for one bit). |
| 2026-10-08 | **Unknown skip reasons are kept and worded generically:** "{Name} wasn't available on {Agent}, so this run went without it." (`weren't` / `them` for several). `SkipReason` gained `'unavailable'`; that sentence comes after the not-signed-in and needs-reconnect ones. | A producer newer than routines must not make a skip vanish. Cost if wrong: none. | Drop unknown reasons (rejected: silent). |
| 2026-10-08 | **At most 3 names per reason group, then "and N more"** ("Gmail, Linear, Notion and 4 more aren't signed in on Bob, …"). If the text still passes the 300-char cap, fewer names are shown (down to 1) before the clamp. | Both sentences survive the cap with ordinary names (tested: 12 names + one needs-reconnect). Cost if wrong: none. | Clamp the joined text only (rejected: a long first sentence ate the second). |
| 2026-10-08 | **`stashConnectorsSkipped` logs `routines_connectors_skipped_entries_dropped` (warn, counts only: received / malformed / overCap)** when a payload for a REAL in-flight fire loses entries. A contract test feeds chat-orchestrator's real `connectorsSkippedPayload()` (now exported from `@ax/chat-orchestrator`; `@ax/routines` devDep) through it. | Producer/consumer drift shows up instead of shortening a warning silently. | No log (rejected: invisible drift). |
| 2026-10-08 | **Operational: the FIRST routine run after a sign-in expires still ends `terminated: connector-needs-reconnect`.** The needs-reconnect marker is written by that run's own failed refresh; runs from the second one on skip the connector and record the warning. | Expected, not a bug: the skip reads `mcp-oauth:status-batch`'s marker, which doesn't exist until a refresh fails. | — |
| 2026-10-08 | **The orchestrator's skip log key changed** from `connectors_skipped_not_signed_in` (ids only) to `connectors_skipped` (`connectors: [{id, reason}]`). | One key for both reasons. Cost: log queries on the old key go quiet. | Keep two keys (rejected). |
| 2026-10-08 | **Residual ruling: a routine turn retires a warm session ONLY when it is idle** (no unsettled waiter in `reqIdsBySession`/`waitersByReqId` — `sessionBusy`). A busy session keeps queue-into-session routing; that routine turn fires `chat:connectors-skipped` for its own reqId from the skip set recorded when the session spawned (`skippedConnectorsBySession`: ids, labels, reasons — never refs; dropped wherever `skippedConnectorRefsBySession` is). Empty set → no event. | Retiring on every routine turn cut a still-running fire on a shared conversation (webhook burst, cron shorter than the run, fire-now mid-run) and pulled its credentials. A session's tools are fixed at spawn, so its spawn-time skips are exactly what a queued run goes without. Cost if wrong: none known. | Always retire (rejected: cuts the in-flight fire); serialize fires upstream in routines (rejected: nothing upstream sees the overlap). |
| 2026-10-08 | **Settle writes the warning when `reachedAssembly \|\| entry.skips.length > 0`.** | Stashed skips prove the turn reached assembly, whatever the outcome says afterwards. Cost if wrong: none. | Trust the outcome alone (rejected: a post-assembly throw dropped a true warning). |
