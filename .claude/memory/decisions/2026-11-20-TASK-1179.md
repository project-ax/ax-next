# Decisions — TASK-1179

| Date | Decision | Rationale | Alternatives |
|---|---|---|---|
| 2026-11-20 | A team agent's own bot binds a channel with the `remember` of the SAME agent's shared-app binding of that channel; with none, ON. | The design doc settles the default: "Each connected channel has a ... switch, on by default", and a bot's first mention *is* its connection (§4). The bug was only that an explicit OFF was dropped. | Default OFF for a no-prior bot bind (the brief's fallback "if the doc doesn't settle it"): rejected, the doc settles it, and OFF would silently stop memory in every newly invited channel with no switch to turn it back on (bot channels aren't listed in settings yet). |
| 2026-11-20 | Another agent's switch on the shared binding does NOT carry. | The switch is per (channel, agent): it decides whether *that* agent learns there. The brief scoped it to "the same agent". | Carry any OFF: more conservative, but conflates two agents' settings. |
| 2026-11-20 | `ChannelStore.upsert` takes an optional `remember`, written by the INSERT only (the conflict's SET leaves it). | Atomic: bind-then-`setRemember(false)` leaves a window where a concurrent mention's `recordThread` reads the switch ON and that thread is captured. A reconnect still keeps the stored switch. | Insert then setRemember: racy, rejected. |
| 2026-11-20 | No teamId check between the shared install and the bot when reading the shared binding. | Slack channel ids are globally unique; a mismatch can only find no binding, which yields the same ON default. A check would add a fall-to-ON branch for a null shared teamId. | Require `shared.teamId === bot.teamId`. |
| 2026-11-20 | A failed read of the shared install or binding fails the bind (`say.failed('bind')`) before anything is written. | Never guess the switch: guessing ON is the bug. | Default ON on read failure: rejected. |
| 2026-11-20 | Planned and implemented inline rather than dispatching ax-planner and per-task implementers. | ~40-line fix in two source files; the orchestrator asked to keep it small, and the design read was already done to scope it. ax-code-reviewer still reviews the whole branch. | Full planner dispatch: cost out of proportion. |
