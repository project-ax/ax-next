# TASK-889 — Connectors in agent settings

| Date | Decision | Rationale | Alternatives |
| --- | --- | --- | --- |
| 2026-10-08 | Remove Connectors from WORKSPACE_AGENT_TABS; parse legacy connectors and rules URLs as agent-settings connectors. | WorkspaceShell canonicalizes with replaceState, preserving bookmarks and history behavior while exposing one destination. | Keeping an invisible tab would retain a competing route. |
| 2026-10-08 | Reuse AgentSettings' ConnectorsTab host and existing reads/writes; keep details, add, sign-in, keys, grants and abilities flows. | TASK-888 already provides the full-width host and preserves mounted chat state. | Rebuilding connector management would duplicate its permission/security rules. |
| 2026-10-08 | Wide connector rows show authoritative health status, an icon and direct details/sign-in actions; no action counts. | AgentConnectorRow has health/account metadata but no action summary or verdict counts. Inventing Figma's illustrative counts would make a false permissions claim; details remains the source for per-tool rules. | Adding list DTO/hook fields or per-row tool reads solely for decorative counts was unnecessary. |
| 2026-10-08 | Preserve fixed /oauth/connected popup bridge; append trusted consumed pending agentId to callback query; derive full-page local settings path in channel-web. | Popups must still postMessage/close. App's old full-page fallback always returned to '/', losing the agent; fixed local construction also avoids arbitrary redirect targets. | Changing callback to settings directly would bypass the bridge; storing arbitrary return URLs would widen the redirect surface. |
| 2026-10-08 | Give What {agent} can do its own grouped built-in abilities section inside Connectors. | The requested copy distinguishes builtin capabilities from third-party connector tools without changing persisted tighten-only overrides. | Separate ability URLs outside the established six sections would add scope. |

Predecessor learnings confirmed: AgentView stays mounted while settings is visible, direct compact links drill into their section, and the skipped-connectors notice refresh key includes settingsSection. Chat connector warning/error shortcuts now enter settings directly and close the mobile Details sheet.

Security: no hook, IPC, dependency or capability changes. Connector names/accounts/health are escaped React text nodes (accounts retain bdi). OAuth callback uses only the agent bound to single-use user-checked state; provider callback query targets are ignored. Full-page settings paths encode the ID as one segment and reject empty/dot IDs through the existing route parser.
