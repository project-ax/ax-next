## 2026-10-03 — TASK-761 connectors walk fixes (auth-before-attach, API-key mode, footer, aisdk)

| Date | Decision | Rationale | Alternatives |
|---|---|---|---|
| 2026-10-03 | **Auth-before-attach is enforced in the channel-web route (`POST /api/workspace/agents/:id/connectors`), not in `agents:attach-connector`.** Every credential slot must resolve via `credentials:get` under ctx (agentId, caller) — the same lookup a turn and the mcp-oauth status route make. `credential-not-found` / `NeedsReconnectError` (by name, on err or `.cause`) → 409 `connector-needs-sign-in` / `connector-needs-key`; missing service / other error → 503; `connectors:get` not-found → 404. | The hook would need new `calls` edges (credentials, connectors) in @ax/agents' manifest — TASK-759 is reworking boot/call cycles in parallel and the card named this route. Routes already gate optional hooks with `bus.hasService` without declaring them. | Hook-level gate (covers the admin agent editor's set-whole-list path too — filed as a followup); a non-refreshing presence hook (doesn't exist; would be a new boundary). |
| 2026-10-03 | **Refs come from channel-web's `lib/connectors.ts` `deriveCredentialPlan`, imported by the server.** | It's the function the browser's connect flow WRITES refs with, and is pinned to @ax/connectors' rule; one less copy. | Re-deriving `account:<id>` inline (drifts on multi-slot / header slots). |
| 2026-10-03 | **Non-admin + `keyMode: 'workspace'` → 403 in the route BEFORE any vault read.** | Same answer the hook gives; avoids the host reading company-key presence on behalf of someone who can't attach it. | Let the gate read then the hook refuse (409-vs-403 would reveal whether a company key exists). |
| 2026-10-03 | **Previously, attaching an id the caller can't see was a tolerated no-op; now it's 404.** | The gate needs the connector record; an invisible id never resolves at runtime anyway. | Skip the gate for invisible ids (would re-open the attach-without-auth hole for anything `connectors:get` hides). |
| 2026-10-03 | **Editor API-key mode = `useKey` draft flag; effective `signIn` is `'none'` with header slots.** Saved connector with header slots and no OAuth slot reopens in key mode. | Server store already accepts `Authorization` when no OAuth slot shares the server; no server change needed. | A third `signIn: 'key'` value (touches every consumer of signIn). |
| 2026-10-03 | **Details footer: `sticky -bottom-5 -mb-5 pb-8 z-10`.** Measured (Playwright, real classes): with `bottom-0` the footer sat 20px above the scroller bottom (AgentRail scroller has `pb-5`; sticky stops at the padding edge) and rows painted in the gap. Test pins the pairing by walking to the real scroller in the rendered AgentRail. | Local fix; the alternative (own inner scroller in the details view) means the rail scroller can't scroll for that tab. | Remove `pb-5` from the rail scroller (affects every tab). |
| 2026-10-03 | **`connectorsSupported` is an allow-list: `runner === undefined || runner === 'claude-sdk'`.** UI hides Add (header + empty state) and shows "<agent>’s model can’t use connectors yet…" in list and details; server still allows attach. | A future runner shouldn't silently claim connectors work; attach on an aisdk agent grants no reach, so refusing it buys nothing. | Deny-list `aisdk` only. |
