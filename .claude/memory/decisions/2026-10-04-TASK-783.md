# Decisions — TASK-783 (MCP OAuth error paths: name the connector, not-found → reconnect, neutral 502, code-only logs)

| Date | Decision | Rationale | Alternatives |
|------|----------|-----------|--------------|
| 2026-10-04 | **The proxy names the failing credential by the CALLER's env key, not by ref or connector id.** `proxy:open-session`/`rotate-session` rethrow a per-ref `credentials:get` failure as `PluginError{code:'credential-resolve-failed', diagnosis:{envName}, cause:<original>}` with a FIXED message. | The env key is the caller's own vocabulary (it handed the map in), so no new field leaks into the hook surface and the proxy needs no idea what a "connector" is. Fixed message: the bus wrapper copies the resolver's message (which can be an OAuth `error_description`) and this error is logged/audited downstream. | Attach `connectorId` (rejected: the proxy doesn't know connectors — invariant 1); keep the inner code as the outer code (rejected: callers read the chain anyway). |
| 2026-10-04 | **Orchestrator walks the `.cause` chain (bounded at 8, cycle-safe) for `NeedsReconnectError` / `credential-not-found` / `credential-resolve-failed`.** Moved into `chat-orchestrator/src/proxy-errors.ts`. | The proxy wrap adds a level: production chain is now proxy → bus → resolver, so the old `err`/`err.cause` check would have silently stopped matching. | Keep the 2-level check (would have broken TASK-713's mapping). |
| 2026-10-04 | **`credential-not-found` maps to `connector-needs-reconnect` ONLY when the env key maps (via the fold's `slotOwners`) to a connector; on the provider key it stays `proxy-open-failed`.** Detail line `Connector: <connectorLabel>` (control/format chars stripped, clamped 64 code points — the same helper TASK-806's prompt line uses, now exported as `connectorLabel`). | Card item 2. TASK-806 left the race/faulted-presence case as `proxy-open-failed` only because the ref was anonymous; that reason is gone. Reconnect label's "reconnect it" covers the rail's "Sign in" button too (TASK-774 wording). | `connector-needs-sign-in` for a missing row (rejected: card says reconnect; that code is replay-only since TASK-806 and has no live-strip button). |
| 2026-10-04 | **A failed warm `proxy:rotate-session` RETIRES the session at its next turn (`stale_session_respawn` reason `credential-rotation-failed`), for ANY rotate failure.** The fresh open then re-resolves per ref and surfaces the named reconnect error. | Rotation fires at turn END — that turn's SSE is done, so there is no live turn to put an error on. The next turn is where the person would hit the dead token; re-spawning reuses the open path's classification instead of a second copy. Any failure, not just reconnect: a session whose credentials could not refresh is running on stale ones; the cost of a blip is one cold start. | Fire a turn error at turn-end (no live stream to receive it); retire only on reconnect-shaped failures (rejected: a second classifier, and a stale-token session is worth replacing anyway). |
| 2026-10-04 | **Log sites (open-failure close, warm deferred close, finally close, rotate) log `errorLogFields(err)` = name, code, innermost causeName/causeCode, clamped to 64 — never `err` or a message.** Rotate also logs `envName`. | Card item 5. The logger serialises `err` including the bus wrapper's message, which embeds the inner resolver message. | Log `err.message` clamped (rejected: still provider text). |
| 2026-10-04 | **mcp-oauth `begin` 502 body is a fixed sentence** ("Couldn't start sign-in with this service. Try again in a moment. If it keeps happening, ask an admin to check the connector's address."). | Card item 4. The UI (`use-oauth-popup`) shows its own sentence and only console-logs this one, so the change is invisible to users and removes the echo. Mentions an admin because the person signing in usually can't edit the address. | Reuse the discover-hosts sentence ("Check the MCP URL") — admin-surface wording. |
| 2026-10-04 | **Implemented inline rather than one subagent per task.** | Three small, tightly coupled edits across 3 packages; context stayed well under budget. Mutation-checked instead: 4 mutants (classifier, rotation retire, 502 echo, proxy message echo) each reddened their tests. | Subagent per task (overhead > work). |
