## Refuted / corrected

- The card body located the `HEAD_SHA` assert in `references/github-project.md`. It is
  not there: the three sites are `auto-ship/SKILL.md` (merge queue), `yolo-ship/SKILL.md`
  Phase 6 and Phase 7. Nothing in the fix depends on this, but the pointer is wrong.
- **The first builder's own mutant table was wrong, and it was wrong in the direction
  that flatters the patch.** It recorded `--verify --quiet "…^{commit}"` → bare
  `rev-parse` as **2 red**, i.e. as a load-bearing line. Re-run on the finished block it
  is **0 red**. The premise held (bare `rev-parse` echoes any 40-hex string back at rc 0,
  measured) but the conclusion did not: the garbage it lets through is rejected one line
  later by `merge-base --is-ancestor`, because a nonexistent object is not an ancestor of
  anything. The two arms overlap and the ancestry arm wins. The flags stay — they buy the
  clean "missing/ambiguous/unknown" message instead of a `merge-base` error on stderr —
  but they are belt-and-braces, exactly like the 40-char assert, and the note now says so.
  The generalisable lesson: a mutant table measured against an INTERMEDIATE state of the
  patch and then carried forward unmodified is evidence of nothing, and it reads as
  evidence of everything. Re-run the table against the head you are shipping. (Recorded
  twice over, because the resuming builder then made the same mistake in miniature: the
  first draft of the whitespace test's comment claimed it pinned the raw-vs-quoted splice.
  It does not — both spellings fail closed on every input, so nothing separates them. The
  comment was corrected before commit rather than shipped as a second false claim.)

**Residual named, not resolved.** `RAW_REVIEWED=<reviewed-sha>` is an unquoted splice of
semi-trusted handoff text. An accident fails closed and loud (verified, both shells); a
hostile `$(…)` value executes and resolves to the head, which is the "handoff names
`HEAD`" hole restated. Double-quoting does NOT fix it (`$( )` expands inside double
quotes) and would make it look handled — the real fix is a quoted-delimiter here-doc,
deferred. Mitigation today is the handoff contract plus Q1. Both holes are written into
the block's own NOTE rather than left to a reviewer to rediscover.

## Trap hit while measuring

`git checkout origin/main -- <path>` writes the INDEX as well as the worktree, so the
usual restore — `git checkout -- <path>` — restored the *mutant*, silently, and the next
mutant was applied on top of it. Use `git checkout HEAD -- <path>` for every mutation
restore, and assert `git status --short` is empty between mutants rather than assuming.
