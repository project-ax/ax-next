## 2026-10-02 — TASK-737: admin per-tool default permissions in the connector editor

| Date | Decision | Rationale | Alternatives |
|---|---|---|---|
| 2026-10-02 | **Did NOT subscribe to `connectors:tools-discovered` to seed admin defaults** (the brief and TASK-735's learning suggested it). | Seeding writes rows nobody reviewed. The only seed that changes anything is `readOnlyHint → allow`, and that hint is the server's own untrusted self-description (design §2: "never a security claim"). Auto-seeding it turns a third party's claim into an Allow grant without a human looking. Seeding `hold` is a no-op (no default already caps at hold). The pre-fill lives in the editor instead: shown to the admin, written only when they press Save. | Subscribe and seed (rejected: loosening from untrusted input); seed only `hold` (rejected: dead code). |
| 2026-10-02 | Routes live in `@ax/connectors` (`GET/PUT <base>/:id/tool-permissions` under both `/admin/connectors` and `/settings/connectors`), authz = the same `isReadOnly` gate PATCH uses. | One authz rule for "may edit this connector"; the connector plugin already owns it and can derive the connector's tool namespaces in-process (row owner == actor whenever `canEdit`). | Routes in channel-web server (rejected: would duplicate the canEdit rule). |
| 2026-10-02 | PUT validates every toolKey's namespace belongs to THIS connector before calling `tool-policy:set-connector-defaults`. | That hook does not check namespace ownership, and its upsert conflicts on `(tool_namespace, tool_name)` and rewrites `connector_id` — without the route check, an editor of connector A could overwrite connector B's defaults by sending B's keys. | Trust the hook (rejected — the hook explicitly delegates authz to the caller). |
| 2026-10-02 | Snapshot-on-attach lives in the `agents:set-connector-attachments` hook (newly added ids only), resolving namespaces via `connectors:resolve` under the agent owner (personal agents) else the actor; non-fatal on failure. | The hook is the single write path, so every route that attaches gets it. Only NEW ids snapshot — re-snapshotting an existing attachment would apply a later admin loosening, which decision 2 forbids. Failure leaves no override, so the live admin default still caps the agent: nothing loosens beyond what the admin set. | Snapshot in the route (rejected: a second caller would skip it). |
| 2026-10-02 | Editor saves only rows whose displayed verdict differs from the saved one (unsaved pre-fills included); the section is always visible, not collapsed. | A pre-fill becomes real only when the admin has it on screen and presses Save. | Collapsed disclosure (rejected: Save would write Allow rows the admin never saw). |
| 2026-10-02 | Tool permissions appear only in the remote (http) connector editor, and only for an existing connector. New connector shows a one-line "after you save" hint. | Namespaces + inventory need a saved record; stdio connectors report `unknown` inventory anyway. | Add to the legacy dialog (deferred — no inventory to show). |
