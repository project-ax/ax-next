# Decisions — TASK-G001 (admin-selectable models)

| Date | Decision | Rationale | Alternatives |
|---|---|---|---|
| 2026-09-30 | `@ax/model-policy` owns the allowed-model policy and provider catalog; agents and personal-agent bootstrap consume `models:get-policy` softly. | One owner for policy and catalog, no cross-plugin implementation imports; absent policy service preserves each consumer's legacy fallback. | An agents-owned settings key would mix agent persistence with provider discovery. |
| 2026-09-30 | Removed models move lazily to the Default in `agents:resolve`; stored model choices stay intact. Derive `anthropic/*` runners as `claude-sdk`, others as `aisdk`. | Re-adding a model restores the owner's choice without migration; a non-Anthropic model cannot run through Claude SDK. Existing warm sessions retain their frozen configuration. | Rewrite all agent rows on save, losing the original choice; retire running sessions on policy changes. |
| 2026-09-30 | Serialize policy read/check/write saves in process and guard read-cache publication with a generation; partition catalog caches, pending reads, and throttles by user plus provider. | The host is single-replica, but awaited reads still race successful saves. Credential resolution depends on user identity, so catalog state cannot be shared across admins. | A cross-replica lock is unnecessary under the chart guard; provider-only caches expose another admin's credential availability. |
