# Decisions — SIGNINS-3 (agent-owned connector sign-ins, slice 2b: delete cleanup + one-time boot removal of non-admin connectors)

Shard id `SIGNINS-3` covers slice 2b (`memory-write-target.sh` refuses `SIGNINS-2B`). Spec: `docs/plans/2026-10-07-agent-owned-connector-sign-ins-design.md`; plan: `docs/plans/2026-10-07-agent-owned-sign-ins-slice2b-plan.md`.

| Date | Decision | Rationale | Alternatives |
|------|----------|-----------|--------------|
| 2026-10-07 | **`connectors:deleted` carries `idStillLive: boolean`, and it is the owner-free cleanup signal.** Subscribers (@ax/agents detach, @ax/mcp-oauth markers) act only on a literal `false`; `true`, missing, or malformed → keep data. `connectors:live-ids` (ids-in, live-subset-out, capped at `LIVE_IDS_MAX` 500, grammar-validated) answers the same question in bulk. | Connector ids aren't unique across owners, so "this row was deleted" doesn't mean "this id is gone". Agents and markers are keyed by id alone, so they need the id-level answer, and it must fail toward keeping data. | Send the owner and let subscribers decide (rejected: owner-specific vocabulary, and every subscriber would re-implement the survivor check). |
| 2026-10-07 | **@ax/agents has a boot sweep (`dropDanglingConnectorIds`, via `connectors:live-ids`) as well as the subscriber.** | Connectors' init fires its boot-sweep events BEFORE agents (and mcp-oauth, and the orchestrator) subscribe. Measured k8s init order: credentials 3, auth-better 5, tool-policy 8, connectors 9, agents 12, mcp-oauth 42. The sweep also catches events lost when the host died mid-fan-out. Agents hard-codes batch 500 to mirror `LIVE_IDS_MAX` (no import); a lower cap would make the sweep fail safe into a no-op. | Make connectors init later (rejected: a fragile ordering contract that doesn't help lost events). |
| 2026-10-07 | **A delete purges people's (user-scope) `account:<id>[:SLOT]` keys only when the id is dead** (`credentials:purge-account` scopes `['agent','user']` iff `!idStillLive`; `['agent']` otherwise). Agent sign-ins go whenever no live SHARED same-id connector survives. | A surviving private same-id connector's users may hold exactly those user-scope rows. | Always purge both scopes (rejected: wipes a survivor's keys). |
| 2026-10-07 | **One-time non-admin sweep at connectors init.** Marker table `connectors_v1_boot_steps`, step `non-admin-connector-removal`, written only after a COMPLETE pass. Per row: purge → soft-delete → announce (a crash leaves the live row for the next boot). Fail-safe: no `auth:get-user` provider → skip, no marker; owner lookup throws, answers anything but an explicit `null` or an object with boolean `isAdmin` → keep that owner's rows, no marker; any purge step failing (`purgeConnectorState` returns `{ failed }`) → keep the row live, don't announce, no marker; a row-processing throw → same. An unparseable row is kept and logged but does NOT block the marker (it's permanent, so retrying forever would make the sweep a standing rule). Losing the soft-delete race to another replica (`softDelete` → false) is not a failure. | Product owner, 2026-10-07: "Remove all existing connectors that were made by people (not admins)" and "I don't care if existing skills are broken", so `'system'`-owned connectors (skills cap-migration) are removed too. One-time so a later-demoted admin's connectors, or one made before the non-admin create paths close, aren't swept. A failed purge must block: tombstoning a row with keys still stored lets a later same-id connector inherit them. | A standing rule every boot (rejected: deletes connectors of later-demoted admins); tombstone even on purge failure (rejected after final review: stranded keys). |
| 2026-10-07 | **Slice 5 must drop person AND agent reconnect markers for ids that aren't live.** | @ax/mcp-oauth subscribes to `connectors:deleted` but inits after connectors, so it misses every boot-time removal; its markers for those ids stay until slice 5's migration. | Give mcp-oauth its own boot sweep now (deferred to slice 5, which already owns that migration). |
| 2026-10-07 | **Authored drafts (`connectors_v1_authored`) proposing a removed id are left alone in 2b — slice 2c owns drafts.** | 2c moves proposals to admins and decides what happens to existing drafts; 2b deleting them would pre-empt that. | Delete drafts with the connector (deferred to 2c). |
| 2026-10-07 | **Cross-plugin composition test lives in `presets/k8s/src/__tests__/connector-delete-composition.test.ts`** (real connectors + agents + credentials + mcp-oauth, kernel order, stub `auth:get-user`). | Plugin source can't import across plugins; presets may. Per-plugin tests stub the other half, so only this one proves the two halves agree on payload and boot order. | — |
