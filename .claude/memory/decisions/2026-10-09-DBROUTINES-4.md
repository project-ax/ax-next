# DB-backed routines — Task 4

- Routine services resolve the real ctx.userId through agents:resolve, then agents:can-manage-routines (personal owner/team admin, no admin payload). Team execution owner stays pinned; another team admin can stop/delete only. Personal management reads/mutations reconcile owner AND mint a new revision, matching the tick helper.
- auth:get-user returns the raw User|null, unlike auth:require-user's {user}. Default catalog services check the raw user's isAdmin === true; initialization context never goes through human ACL.
- HookBus.call timeouts do not cancel handlers. Host-only callJoined adds invocation-scoped AsyncLocalStorage tracking of actual nested service handler promises, waits for settlement before returning/rejecting, and preserves deadline failure. Each explicit nested joined boundary owns its own wait (otherwise an inner lock can release while an outer joined call waits). No hard wall-clock guarantee for a provider that never settles; lock safety takes priority, per controller ruling. Ordinary call behavior is unchanged. Locked routine secrets and durable cleanup use callJoined, with no cross-plugin transaction handle.
- acceptDispatch now returns {accepted: AcceptedDispatch, replayed: boolean}|null. The replay bit is calculated inside the locked receipt transaction and never persisted in its result. Adapters invoke only when replayed is false; a preflight receipt lookup alone has a concurrent duplicate-invoke race. Stored dispatch receipt stays canonical AcceptedDispatch.
- Canonical services register through the actual routines plugin. Legacy workspace writer/token rebind subscriptions and route map were removed early because they cannot operate on the new store. Task8 must wire the private dispatch callback, scheduled fire/finish, static webhook router, and periodic cleanup; Task11 removes remaining dead legacy modules/tests. Fire-now fails closed without the adapter. Intermediate task commit is not deployable.
