# Decisions — SIGNINS-5 (agent-owned connector sign-ins, slice 3: agent-owned sign-in + all-or-nothing Add)

Shard id `SIGNINS-5` covers slice 3. Spec: `docs/plans/2026-10-07-agent-owned-connector-sign-ins-design.md`; plan: `docs/plans/2026-10-07-agent-owned-sign-ins-slice3-plan.md`.

| Date | Decision | Rationale | Alternatives |
|------|----------|-----------|--------------|
| 2026-10-07 | **A private connector's OAuth `begin` answers 403 `agent-store-refused`** (it used to fall back to a user-scope sign-in). | Every connector is admin-shared after slice 2, and agents never fall back to user scope. Cost if wrong: a leftover private connector can't be signed in until an admin recreates it as shared. | Keep the user-scope fallback (rejected: the downgrade the slice removes). |
| 2026-10-07 | **The dead `credScope` field was removed in this slice, not deferred.** Pre-upgrade in-flight pending rows (`credScope 'user'`) now write at agent scope as `sign-in-again`: an unreadable orphan, inside the 10-minute pending window. | No half-wired code; one small commit. Cost if wrong: one person signs in again after the deploy. | Defer to a later slice (rejected). |
| 2026-10-07 | **OAuth Add on a connector already on the agent → `begin` 409 `already-attached`** (the read/attachment question, asked in `mode:'add'` before any pending row). The client shows "It's already on this agent." | Mirrors the key path's 409. Cost if wrong: a stale Add list shows a refusal instead of a re-sign-in. | Let the Add proceed as a silent re-sign-in (rejected). |
| 2026-10-07 | **An OAuth connector that also declares header api-key slots adds by signing in alone**; the row then needs its header key, so the rail's **Add key** (`PUT …/connectors/:id/key`) is offered on PERSONAL agents too. | Strictly all-or-nothing would need the popup to collect header keys first (a larger UI change). Cost if wrong: such a connector is briefly attached without its header key, and the row says "Add key". | Collect header keys before the popup (rejected for now: larger change). |
| 2026-10-07 | **Accepted: a person's old user-scope key or sign-in can shadow the agent's new one** (lookup is still user → agent → global) until slice 5's flip and purge. | `main` is undeployable until slice 5 anyway. Cost if wrong: dev/test confusion mid-epic only. | Flip lookup in slice 3 (rejected: out of slice scope). |
| 2026-10-07 | **An admin with a missing SHARED key is sent to Admin › Connectors**, not given an in-place entry on the rail. | Shared keys are the workspace's and connectors are admin-defined. Cost if wrong: one extra click for admins. | Rail-side shared-key entry (rejected). |
| 2026-10-07 | **Labels: a row NEVER signed in says "Sign in" (menu item and dialog title); an EXPIRED row says "Sign in again".** The OAuth widget drops "Reconnect" wording ("Sign-in expired", button "Sign in again" / "Sign in"). | Matches the details view; the owner named "Sign in again" for expired rows. Cost if wrong: one label. | "Sign in again" for both (rejected: "again" is false for a first sign-in). |
| 2026-10-07 | **The menu item opening `ConnectorDetails` is "Edit" for everyone, members included.** | The view is editable within the TASK-809 ceiling, so "View details" misleads. Cost if wrong: members think they can change more than they can (the ceiling is still enforced). | Members get "View details" (rejected). |
| 2026-10-07 | **`sharedSignIn` ("Team sign-in expired") is set only for a TEAM agent.** A personal agent's expired agent-scope sign-in is the plain needs-reconnect state ("Sign in again"). | Every agent-scope row is the agent's own sign-in, so a marker keyed on the agent alone does not mean "team". | Flag every agent-scope marker (rejected: wrong copy on personal agents). |
| 2026-10-07 | **`prompt` on the authorize URL is MERGED, not overwritten**: `select_account` first, `consent` for Google, then what the SDK already set, de-duplicated, one param. | The SDK appends `prompt=consent` for an `offline_access` scope (OIDC Core §11); overwriting it cost the refresh token. | Overwrite with `select_account` (rejected: the bug). |
| 2026-10-07 | **Process rulings for the slice's commits:** T3 updated the client key-route path strings so the app works at every commit, while the retry/team-sign-in client methods went with their menu items in T5; T4 made `ConnectorOAuthConnect`/`useOAuthPopup`/`beginOAuth` require `agentId` + `mode` and fixed every caller; T5 deleted `ConnectorConnectDialog` once grep showed no user; client Add was knowingly broken between the T3 and T4 commits (400/409). | One PR; bisect-only costs. | Land the slices as separate PRs (rejected). |
