| 2026-11-25 | **The access rule.** `checkAccess`, personal agent: an owner row → allowed (`owner: true`). Otherwise by audience: `just-me` → forbidden; `list` → allowed iff a `user` member row matches; `everyone` → allowed iff the caller is an AX account; anything else → forbidden (fail closed). Team branch unchanged. "AX account" = a non-empty id that isn't `ownerless:` (`isOwnerlessId`) and that `auth:get-user` answers non-null. `agents:list-for-user` uses the same rule in one SQL filter plus the same account check, so list ⟺ resolve. | "Everyone" must mean every AX account (design §1). | 2026-11-25 | **Hook shapes (boundary review in the PR).** `Agent` gains `audience?: 'just-me'\|'everyone'\|'list'` (personal agents only; absent on a team agent), `shared: boolean` (team agent, or personal with audience ≠ `just-me`; derived on read, never stored) and `isOwner?: boolean` (set by `agents:resolve` and `agents:list-for-user` for the userId asked; `false` on a team agent). `ResolveOutputSchema` declares all three (zod strips undeclared keys). `agents:list-for-user` now returns owned (including co-owned) personal agents, personal agents shared with the user, and team agents of `teamIds`, each with `isOwner`.
