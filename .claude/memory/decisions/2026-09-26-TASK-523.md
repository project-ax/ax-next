# TASK-523 decisions

| Date | Decision | Rationale | Alternatives considered |
|------|----------|-----------|------------------------|
| 2026-09-26 | **Reverses TASK-496's embed/rerank row.** Memory embeddings are `google/gemini-embedding-001:nitro` at 384 dims and reranking is `voyageai/rerank-2.5:nitro`, BOTH through OpenRouter on the one `provider:openrouter` credential (owner decision on the card, 2026-09-25/26). The "missing credential degrades to `semantic`/`ranking`, never a local-hash fallback" half of TASK-496's row still holds. | Vertex's credential was a ~1 h ADC bearer token with no product write path (recall silently went `semantic` on expiry); Cohere had no write path either. OpenRouter is long-lived, already required by the observer, and already has a validate-and-save path on the Provider keys screen. Speed benches on the card; retrieval quality NOT re-measured (owner's call) — rung 4's 84% was measured with Cohere, so the reranker switch is what most likely moves accuracy | Keep Vertex + Cohere with product write paths (still a 1 h token); `openai/text-embedding-3-small` (slower query p50); `cohere/rerank-4-pro` via OpenRouter (slower, ~19x dearer at pool 40) |
| 2026-09-26 | Vertex and Cohere drivers DELETED from `@ax/embeddings`, not kept beside the OpenRouter ones | Only the memory preset configured them; keeping them is code no deployment reaches (half-wired policy) and two extra egress hosts in `endpoints.ts` | Keep all three behind the provider table key (dead code, wider egress) |
| 2026-09-26 | Model id grammar is per-endpoint `vendor/model[:variant]`, lowercase, bounded; still enforced for config (boot `invalid-config`) and payload (degrade to `undefined`) | OpenRouter ids carry `/` and `:`, which the old URL-path grammar forbade. The model now rides in the JSON body, not the URL, so traversal is moot — the grammar stays as defense in depth | Drop the grammar (any string to the provider); keep the old grammar (rejects every OpenRouter id) |
| 2026-09-26 | No task type (`input_type`) on the embed wire; body is exactly `{model, input, dimensions, encoding_format}` for query AND document, pinned by a test. `EmbeddingTask` stays on the hook | OpenRouter's OpenAPI lists `input_type` ("e.g. search_query, search_document") but not whether its Google route maps it to Gemini's task type, and no key was available in the builder session to probe it. An unmapped field could 400 and take the dense channel dark | Send `input_type` unverified (risk: whole dense channel down); drop `task` from the hook (it is vendor-neutral and other producers use it) |
| 2026-09-26 | Embed-model fingerprint is STORE-level, owned by `@ax/memory-facts-sqlite`: a meta row holding the configured `embedder.model`; on open, a mismatch (or vectors present with no fingerprint — pre-TASK-523 Vertex vectors) deletes every `vec0` row in one transaction and records the new model | The store already sends `model` in the `embeddings:embed` payload and the producer honours a payload model, so the store's configured model IS the model that made its vectors — no hook-surface change needed. One vector space in `vec0` at a time means no mixed-model comparison is possible | Per-row model column + filtered dense channel (more schema, same effect); a `model` field on `EmbedOutput` (hook-surface change + boundary review for the same guarantee) |
| 2026-09-26 | Re-embed trigger: after a `memory:facts:record` whose embed SUCCEEDED, if that agent has rows without vectors, the store runs the existing bounded vector backfill detached and single-flight per agent | Nothing in production calls `memory:facts:reindex`, so vectors wiped on a model change — or never written because the key was missing at record time — would never come back. A successful embed proves producer + credential are healthy right now | Await the backfill inside record (adds latency to the observer and the note tool); a boot-time backfill (no user ctx, so no credential lookup) |
| 2026-09-26 | Live kind verification NOT done by the builder; handed to the walk lane | The kind cluster is shared and serialized through auto-ship's walk lane — a builder redeploying it can clobber a walk in flight. No OpenRouter key in the builder session either | Redeploy the shared cluster from a builder worktree |
