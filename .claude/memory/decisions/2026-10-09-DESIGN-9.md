The browser geometry script now waits for the actual memory row before selecting table/card shape, and checks statement content width after cell padding. Browser smoke uses controlled API fixtures against the actual local SPA; it does not claim live OAuth or backend acceptance. Preferred in-app browser tools were unavailable, so the standalone Playwright already installed in preset-k8s was used with cached Chromium.

Independent review found two more integration regressions. At 768px the expanded sidebar and details rail left a 24px textbox and overflowed Send; at 768×400px centering the oversized welcome group hid its title above the scroll origin. The new real-browser composer regression reproduced both before the fix. Agent details now reuse their existing sheet below lg, while navigation/settings keep md; welcome uses safe centering. The regression measures textbox and button bounds, scroll-origin reachability, Send visibility, and retained drafts across settings at 320/390/768/900/1024/1440px, including short windows and both themes.
