| 2026-11-15 | **A rename sends Slack the WHOLE manifest as this build makes it: `apps.manifest.update` with `app_id` and `buildAppManifest(name, slackUrls(publicOrigin, installId))`. Only the two name fields differ from what Connect sent.** | `apps.manifest.update` replaces the manifest, so a name-only body would silently drop interactivity (TASK-1095), the `/ax` command and the scopes. A name-only manifest: Slack drops everything else. |
| 2026-11-15 | **`SlackApi.updateApp(configToken, appId, manifest): Promise<void>`; `permissions_updated` is not read.** Form body `{ app_id, manifest: JSON.stringify(manifest) }`, Bearer config token, like `createApp`/`deleteApp`. | The manifest carries the scopes this build connects with, and every production install already has all nine (#1180 shipped them together, deployed rev 86), so `permissions_updated` can't be true for a real install today. | 2026-11-15 | **Route `POST /admin/slack/rename`, body `{ botName }` → 200 `{ botName }` (the tidied name). Holding the in-process lock keeps a rename from interleaving with Connect, Disconnect or a callback. `RouteSpec.method` is GET or POST only (`http-types.ts:35`). | `/admin/slack/bot-name`. PUT or PATCH (not in `RouteSpec`). |
| 2026-11-15 | **Only an ACTIVE install can be renamed; a pending one answers 409 `not-connected`.** | The UI offers Rename only on the connected card. A pending install is cheaper to Cancel and Connect again (no channels yet). One fewer state to test. | Any status: the config token can update an app nobody has installed yet, but nothing would call it. |
| 2026-11-15 | **Slack first, then the row (`InstallStore.setBotName`, `WHERE install_id = $1 AND status = 'active'`, throws `InstallStoreError('install-not-active')` when no row matches).** | AX's row shows only a name Slack confirmed. | 2026-11-15 | **Rename errors: 502 `slack-config-token` (refresh token missing from the vault, or rotate/update refused with `invalid_auth`, `not_authed`, `token_expired`, `token_revoked`, `account_inactive` or `invalid_refresh_token`); 502 `slack-name` (`invalid_manifest` at update); 502 `slack-error` (anything else from Slack: `ratelimited`, `timeout`, `network`, a 5xx, `app_not_found`...); 500 `internal` (a vault or store fault). Log fields stay inside the four keys the leak test allows (`admin-routes.test.ts:1471-1476`). | Reuse `slack-token` with copy chosen by context. Split "missing" from "refused" (same remedy). A `slack-unconfirmed` like Connect's (no orphaned app can result from an update). |
