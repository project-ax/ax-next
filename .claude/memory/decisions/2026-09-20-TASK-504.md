## Gotcha for the next agent

`ternary` takes a **real bool**, so `(include "ax-next.bool" x) | ternary a b` errors with `wrong type for value; expected bool; got string`. Compare instead: `(eq (include "ax-next.bool" .Values.x) "true") | ternary a b`. Both MinIO call sites in `host/deployment.yaml` needed it.

Also: a gate can be *defective and invisible*. `sandbox.devServices.enabled` renders no manifest of its own — its only consequence is the k8s 1.29+ guard — so a render-diff matrix that skips that guard compares two identical outputs and proves nothing. It needed a per-gate context override to become observable.
