| 2026-09-26 | `'semantic'` now means "the dense channel did not contribute", measured on the channel's OUTPUT: raised when no query vector, OR the dense search returned nothing while the fused list is non-empty (the scope held rows). The old probe was "did the query embed succeed?", which reported `degraded: []` over an empty `vec0` right after TASK-523's model-change wipe (measured on kind, walk TASK-589; reproduced red on main by `embedding-fingerprint.test.ts`). | A query vector is not a contribution. The fused-list-empty carve-out mirrors `'ranking'`'s: the temporal channel admits every in-scope row regardless of query, so an empty fused list means no rows in scope and nothing was lost — a day-one empty store with a healthy embedder stays `[]`. Decided in the store region where `dense` is in hand, so no extra query. | Count the tenant's vectors (`= 0` ⇒ semantic): one more store read, and misses the owner/about-scoped case where OTHER rows have vectors; flag whenever ANY in-scope row lacks a vector (partial-coverage): a per-recall `NOT EXISTS` probe and a much broader semantic change that overlaps TASK-590's re-embed — left as a known limit (partial coverage does not flag). |
