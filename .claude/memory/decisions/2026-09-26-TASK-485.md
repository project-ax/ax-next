# TASK-485 — StateDot: not colour-only, and present in the a11y tree

| Date | Decision | Rationale | Alternatives |
|---|---|---|---|
| 2026-09-26 | Two mechanisms, one per failure: a per-state SHAPE in `StateDot` (circle working, diamond waiting/held, dash resting, square stopped) for WCAG 1.4.1, and the `STATE_WORDS` word as `sr-only` text AFTER the name in the sidebar roster row for 1.1.1. | Shape keeps the scannable one-dot roster and helps every call site for free; the sr-only word reads "Ada, waiting on you" — name first. A visible text label per row would crowd a 236px rail that already truncates names. | Visible text label (too noisy for 4 states in a narrow rail); `role="img"` + `aria-label` on the dot (reads state BEFORE name: "Waiting on you Ada"); tooltip (not in a11y tree reliably, not visible without hover). |
| 2026-09-26 | `StateDot` stays `aria-hidden`; only the sidebar row adds the word. | Every other call site (`DecisionRow` receipt + question row, `TodayView` working list) already has adjacent text carrying the state; naming the dot there would double-announce. All call sites live under `components/workspace/` — workspace-owned, none chat-only. | Name the dot everywhere (duplicate announcements). |
| 2026-09-26 | Shape classes live in a separate `STATE_SHAPE` record, not more `state === … && '…'` arms in the `cn()`. | `theme-contrast.test.ts` `parseStateDotArms` reads those arms into a Map keyed by state — a second arm per state would silently OVERWRITE the fill it measures. | Inline arms (breaks the contrast guard silently). |
| 2026-09-26 | Existing roster-row queries changed from exact `name: 'Quill'` to `/^Quill\s*,/`. | The row's accessible name now includes the state. jsdom inserts a space between element children ("Quill , resting"), so tests fold `\s+,` rather than pin exact spacing. | Put the sr-only inside the `title` span (breaks TASK-436's "clamping element carries exactly the name" assertion). |
| 2026-09-26 | Implemented inline, no per-task subagents. | 2 production files + 1 test, ~60 lines; subagent overhead exceeds the work. | Subagent-driven per yolo-ship default. |
