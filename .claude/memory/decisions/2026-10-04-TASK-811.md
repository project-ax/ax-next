A difference → terminate + fresh spawn (same branch as TASK-612/783/806). No hook-surface change, so no boundary review. Never interrupts an in-flight turn: the check runs only at routing. | (a) New subscriber event `agents:connectors-changed { agentId }` fired by @ax/agents + a per-agent generation counter like TASK-612 (rejected: new hook surface, misses any write path that forgets to fire, and is replica-local). (c) UI caveat "applies to new chats" (rejected: the card's acceptance is the SAME conversation). |
