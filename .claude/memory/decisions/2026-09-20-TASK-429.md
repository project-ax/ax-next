## Measured, so nobody re-derives it

- Radix `ToggleGroup type="single"` (installed version): root `role="group"`, items
  `role="radio"` + `aria-checked`. So the radios had **no radiogroup owning them** — a
  second ARIA defect the card did not mention.
- Radix's roving focus moves focus inside a **`setTimeout`**. A synchronous
  `fireEvent.keyDown` + `expect(document.activeElement)` sees no movement and reads as
  "arrow keys do nothing". Wrap focus assertions in `waitFor`.
- channel-web's tsconfig `include: ["src"]` covers `__tests__`, and
  `noUncheckedIndexedAccess` is on: `const [a, b] = getAllByRole(...)` fails `pnpm build`
  even though vitest is happy. The tempting fix — a bare `const working = () => …`
  accessor — puts a **function** where the element belonged, and `expect(working)` then
  passes against any DOM at all.
