## 2026-10-02 — TASK-734 connectors rail 1/10: canonical connector tool names (`toolNamespace`)

| Date | Decision | Rationale | Alternatives |
|---|---|---|---|
| 2026-10-02 | **`toolNamespace` = `c` + 10 hex of `sha256("ax-connector-tool-namespace/v1\0" + rowOwnerUserId + "\0" + connectorId + "\0" + serverName)`; shape `/^c[0-9a-f]{10}$/`. The owner is the connector ROW's owner, not the requesting user, and the agent is NOT an input.** | Connector rows are keyed `(owner_user_id, connector_id)` (`connectors/src/migrations.ts`), so the id alone does NOT identify a record: a private "linear" and someone else's shared "linear" share an id and must get different namespaces (product owner, 2026-10-02). The same record must map to one namespace for every agent/user/session/restart, because per-agent permissions are keyed `(agentId, toolKey)` in TASK-736. Hashing keeps the owner id out of model-visible tool names; `mcp__c<10>__` is 18 chars, leaving 46 of the 64-char tool-name budget. | `connectorId` alone, as the design doc wrote it (rejected: collides across owners). Including agentId (rejected: product owner said same connector → same namespace). A random id stored on the row (rejected: needs a migration and buys nothing over a deterministic hash). |
| 2026-10-02 | **Wire shape is `toolNamespaces: Array<{ server, toolNamespace }>` (one per `capabilities.mcpServers[]`), on BOTH `connectors:resolve` and `connectors:list-defaults`.** | A connector may declare several MCP servers; the design says "per (connectorId, serverName)", so a single scalar `toolNamespace` cannot be correct. list-defaults also needs it because the orchestrator folds defaults from list-defaults without calling resolve. | Scalar `toolNamespace` as the card body named it (rejected: wrong for multi-server connectors). Adding the field inside `capabilities.mcpServers[]` (rejected: that schema is the stored, shared Capabilities shape). |
| 2026-10-02 | **Orchestrator renames the sandbox `.mcp.json` key to the namespace and DROPS (logs `connector_mcp_server_unnamespaced`) any connector server without a well-formed namespace.** | Fail closed: a server under its author-chosen name would reach the gate as an unattributable `mcp__<name>__<tool>`, which later cards cannot key a verdict on. Only `@ax/connectors` mints namespaces, so the drop path is a drift guard, not a product path. | Fall back to `spec.name` (rejected: silently re-opens the hole). |
| 2026-10-02 | **The claude-sdk runner lifts ONLY `mcp__c<10 hex>__<tool>` to `mcp.<ns>.<tool>` (new class `mcp-connector`); any other foreign `mcp__x__y` keeps passing through verbatim.** | Only host-minted namespaces enter the canonical keyspace; a stray server cannot dress itself up as a connector key by name shape alone. Skills cannot ship their own `.mcp.json` (installed-skills rejects it) or `mcpServers` (TASK-100), so connector servers are the only `.mcp.json` source. | Generic `mcp__x__y` → `mcp.x.y` (rejected: puts unattributed servers into the same keyspace as connector keys). |

### Correction (stale rows elsewhere — archives are frozen, so the correction lives here)

- `decisions.md` TASK-263 rows ("Connector tools reach `evaluate()` as `mcp.<serverId>.<tool>` — dot form, NOT `mcp__<server>__<tool>`" and the "Residual hole" paragraph) and the TASK-700 shard's "a connector tool `mcp.<id>.<tool>`": **wrong for connectors before TASK-734.** `mcp.<serverId>.<tool>` is the `@ax/mcp-client` HOST-tool key (admin-configured MCP servers). Connector MCP servers run in the SANDBOX via per-dir `.mcp.json` (`chat-orchestrator/src/connector-union.ts` `foldConnectorCaps` → `agent-runner-core/src/installed-skills.ts`), so their tools reached the gate as `mcp__<spec.name>__<tool>`, passed through verbatim by `classifySdkToolName`. **Since TASK-734** they reach it as `mcp.<toolNamespace>.<tool>` (`toolNamespace` = `c<10 hex>`). The stale comment in `tool-policy/src/evaluate.ts` that seeded the error was rewritten in the same PR.
- Known residual: `@ax/mcp-client` server ids share the `mcp.<x>.` keyspace; an admin who names a host MCP server exactly `c<10 hex>` could alias a connector's toolKey. Admin-only config, 40-bit target; noted for TASK-736 (verdict store) to reject or reserve.
