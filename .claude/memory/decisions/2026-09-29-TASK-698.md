## 2026-09-29 — TASK-698 `/admin/connectors*` had no admin gate

| Date | Decision | Rationale | Alternatives |
|---|---|---|---|
| 2026-09-29 | **Gate inside `createConnectorRouteHandlers` (one `authenticate()` closure: 401 -> 403 `{error:'forbidden'}` when `mode==='admin'` and `!actor.isAdmin`), not a wrapper at registration and not by importing routines' `requireAdmin`.** | Invariant I2 forbids the cross-plugin import (routines' `shared.ts` copies its helper per plugin for the same reason). Putting it in the handler means every caller of the bundle (the test suite's direct-handler calls, `registerAdminConnectorRoutes`) gets it; a registration wrapper would leave the handlers open to any second registration. Same status/body as every other `/admin/*` route. | Wrap at `registerAdminConnectorRoutes` (rejected: a future second registration silently skips it). Make `base` required (rejected: signature churn across 5 lib functions and their tests; returned as a follow-up). |
| 2026-09-29 | **Implemented inline for the server half; one subagent (sonnet) for the two-call-site UI half.** | The server change is ~25 lines around one closure and I needed the red/green loop against the Postgres harness myself; the UI half is mechanical and independent (different package). | All subagent-driven (rejected: overhead > work for a 25-line change). |
