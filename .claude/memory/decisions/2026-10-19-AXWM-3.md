| 2026-10-19 | W3d-1's production smoke test (rev 47) found four bugs, fixed in #997–#999 (rev 50). (1) An AlertDialog stacked on a Sheet, and (2) a dialog opened from a MODAL DropdownMenu whose trigger then unmounts, both leave `body` with `pointer-events: none`, so the page freezes. Use an inline confirm and `<DropdownMenu modal={false}>`; each has a lock test asserting `document.body.style.pointerEvents !== 'none'`. (3) NFSv3 negative-dentry caching across two NFS clients hid a restored file on the host for 30–90 s. The host read mount is now a static PV with `mountOptions: [lookupcache=positive]`; an inline `nfs:` volume can't carry mount options, and a PV's source is immutable. | jsdom can't see modal-layer bugs. Reproduce them in real Chromium with a throwaway Vite page that renders the real component, driven by Playwright. NFS evidence is in `deploy/kind/nfs-lookupcache-2026-10-19.json`. | `noac` or `actimeo=0`, which are far more expensive; a host-side retry, which hides the cause. |
| 2026-10-19 | W3d-2 (the "Updated project memory" chip). (D1) A turn's versions match the thread by a new nullable `turn_at` column, stamped when the `chat:turn-end` subscriber first sees the turn, before its background pass. Matching uses the memory-used exchange rule, now shared in `server/exchanges.ts`. (D2) The pass finishes after the client's `done` re-read, so a project chat re-runs `load()` about 3 s and 10 s later, guarded against a new turn or a different chat. (D3) Undo runs on the host in `projects:undo-change`. It refuses if a newer version exists, then applies the inverse with a content guard: edited means write the previous bytes with `ifMatch` set to this version's sha; deleted means write the previous bytes with `ifAbsent`; created means hash-check the current bytes, then delete. It is recorded as `restore`. (D4) `projects:conversation-changes` stays general across paths; channel-web keeps only `memory/`. Plan: `docs/plans/2026-10-19-w3d2-memory-chip-impl.md`. | The client has no reqId for a reloaded turn, and `created_at` is when the pass finished, so a late pass would attach to the wrong turn. `restore-version` can't undo a file the agent created and has no guard against a later change. | Persisting reqId on turn rows (ipc-core, conversations and the transcript); matching by `created_at`; an SSE event from projects; having the client compose restore and delete. |
