| Date | Decision | Rationale | Alternatives |
|---|---|---|---|
| 2026-09-29 | **`proxy:open-session` credentials gain an OPTIONAL per-credential `allowedHosts: string[]`; the registry binds each placeholder to (owning session, host set); the listener substitutes a placeholder only when the AUTHENTICATED caller owns it AND the tunnel's CONNECT-target hostname is in that placeholder's host set. Absent / empty `allowedHosts` = never substituted (forwarded verbatim).** | Admin model keys are `scope: 'global'` and ride in every sandbox as a placeholder; `proxy:add-host` / private connectors let any user allowlist a host they control, so before this a placeholder sent to that host got the operator's real key. The allowlist (where a session MAY reach) and the credential binding (where a credential MAY be sent) are different questions; only the second was missing. Optional-on-the-wire but default-deny in the registry: a caller that forgets the field fails closed, not open. | Session-wide flat `credentialHosts` list: cannot express "Anthropic key -> api.anthropic.com only, GitHub token -> github.com only" in one session. Registry-required field at the hook level: would break every stub caller loudly but the fail-closed default already gives the same safety without a flag day. |
| 2026-09-29 | **The destination host is the CONNECT target the proxy AUTHENTICATED, allowlist-checked, resolved and connected to (`handleCONNECT`'s `hostname`, threaded into `handleMITMConnect`), never the inner request's `Host` header or SNI as the client wrote them.** | The proxy dials `resolvedIP` with `servername = hostname`; that is the only host bytes can reach. A client that CONNECTs to evil.com and writes `Host: api.anthropic.com` inside the tunnel still delivers to evil.com, so the tunnel host is the binding key. Keep-alive requests on one tunnel therefore all share one destination. | Parse `Host` per request in the framer: spoofable, and adds nothing since the tunnel cannot change destination. |
| 2026-09-29 | **Substitution is also scoped to the CALLER's own registry map (`registry.replacerFor(sessionKey, host)`); the cross-session `SharedCredentialRegistry.replaceAll*` / `hasPlaceholders` and the map's unscoped `replaceAll*` are DELETED, and `CredentialPlaceholderMap.register` takes `allowedHosts` as a REQUIRED argument.** | TASK-158 left substitution "across all sessions" for this card. The session key is the `sessions` Map key that `authenticateCaller` matched (the same key the plugin registers the map under), not `SessionConfig.sessionId`, which is optional. Deleting the unscoped API makes "substitute everywhere" unrepresentable rather than merely unused. | Keep both APIs and only call the scoped one: an unused foot-gun that a later edit re-wires. |
| 2026-09-29 | **Host comparison is exact after `trim().toLowerCase()` on both sides; no wildcard, no port, no trailing-dot folding.** | Mirrors the allowlist's exact-match rule; the only failure mode is an over-strict miss (placeholder forwarded verbatim = upstream 401), never an over-broad hit. | Suffix / wildcard binding: a bug in matching becomes a credential leak. |
| 2026-09-29 | **Bindings, by credential kind (audit of everything that reaches `proxy:open-session`): provider key (`providerDefaults`) -> `[endpoint.egressHost]` from PROVIDER_ENDPOINTS; explicit agent row creds (dev stub only; production `@ax/agents` returns neither `requiredCredentials` nor `allowedHosts`) -> that agent row's `allowedHosts`, derived by the orchestrator (never read off the credential entry); connector slots (api-key AND oauth->mcp-oauth; this is where skill/git/MCP-OAuth credentials live since TASK-100) -> the connector's `capabilities.allowedHosts`. Skills declare no credentials of their own any more.** | Every credential kind has a trustworthy source: the provider table is code; the agent row and connector caps are operator/owner-curated store rows resolved by the host, not by the model. Host grants (`host-grants:list`) and `proxy:add-host` only widen the SESSION allowlist and deliberately do NOT extend any binding. | Bind mcp-oauth tighter (to the MCP server's URL host): deferred, connector-level hosts are the declared reach and a follow-up can narrow. |
| 2026-09-29 | **Touched the connector fold (`foldConnectorCaps`) by exactly one line + a type widening to stamp `allowedHosts` onto each slot; TASK-697 (credential ref scoping) will edit the same function.** | The connector's hosts and its credential slots are only ever in one place together (the fold); computing bindings elsewhere would duplicate the slot-name scheme. Kept to one statement so the sibling's rebase is trivial. | Post-fold pass in the orchestrator: decouples the diff but duplicates `connectorCredentialEnvName` semantics. |
| 2026-09-29 | **`credential_unbound` warn (env name only, never a value) when a credential is registered with no hosts.** | Default-deny turns a forgotten binding into a silent upstream 401. A loud log line is the cheapest way to make that diagnosable without a new event field. | New field on `event.http-egress` for "placeholder withheld": more hook surface, deferred as a follow-up. |
