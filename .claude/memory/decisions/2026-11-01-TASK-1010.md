## 2026-11-01 — TASK-1010 `artifact.publish` accepts only this session's own `blob.put` shas

| Date | Decision | Rationale | Alternatives |
|---|---|---|---|
| 2026-11-01 | ipc-core keeps an in-memory, bounded record of the shas each session's `blob.put` returned (`handlers/session-blob-puts.ts`). It is keyed by `[sessionId, userId, conversationId]` from the listener-stamped ctx. `artifact.publish` refuses any other sha with `notFound('not found')`, before the hook runs. That is the exact body `mapPluginError` gives the hook's own not-found (a put-then-purged blob). | The runner's only path is put then publish inside one tool call (`agent-runner-core/artifact-publish-executor.ts`), so it passes by construction. The host is single-replica (the chart refuses more), so process memory covers the whole session. A host restart between put and publish costs one failed publish, and a retry re-puts. | A durable DB ledger of puts (more state and a new hook, for a window of milliseconds). A hook-level check in `@ax/attachments` (the hook cannot see who put what without new hook surface). Accepting a runner-supplied list (forbidden by the card). |
| 2026-11-01 | Bounds: the 1024 most recent shas per session and the 4096 most recently active sessions, with insertion-order eviction. | A looping runner cannot grow host memory without limit, and one session's puts can only evict its own entries. No session-end cleanup hook, because the LRU already bounds it (YAGNI). | Unbounded maps (leak). TTL timers (more moving parts). |
| 2026-11-01 | Catch blocks: `attachments.list` logs every hook failure before `mapPluginError`, as #1095 did for blob.get. `artifact.publish` calls `logInternalError` only when the mapped status is 500, so expected 403/404/409 answers do not log as internal errors. | The real HookBus wraps a plain throw as `PluginError{code:'unknown'}`, which used to map to a 500 with no log line. The tests throw that wrapped shape. | Log every PluginError in artifact.publish (noisy error-level lines for routine refusals). |
