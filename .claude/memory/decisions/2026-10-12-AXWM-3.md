| 2026-10-12 | aisdk runner: shared paths are NOT added to `recognizedRoots`. | Spec §3.6 says add them, but `recognizedRoots` is the set of roots under which a top-level `.ax/`/`.claude/`/`CLAUDE.md` is RE-ROOTED onto `/agent` (`governed-paths.ts` `findGovernedSegment`) — adding them would cause exactly the re-rooting §3.6 forbids. | 2026-10-12 | `@ax/shared-folders` calls `sandbox:delete-shared-folder` UNDECLARED, guarded by `bus.hasService`. | Declaring it closes a call-graph cycle (shared-folders → delete → locate in resolver → `shared-folders:authorize-mounts`), which bootstrap rejects even for optionalCalls.
