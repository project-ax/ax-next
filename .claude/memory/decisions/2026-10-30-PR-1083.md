# PR-1083: task reports in everyday words (decisions)

- **2026-10-30.** Agent-written task updates and asks leaked tool syntax onto the task page: "Called routine_fire_now for Walk ping (requestId: …)" and "Please approve the routine_fire_now…". The fix is prompt guidance, not a UI filter. Three places say the same thing:
  - `routine_report`'s description, in `packages/routines-contract/src/tools.ts`;
  - its `update` and `ask` JSON field descriptions;
  - the check-in message's closing line, in `packages/routines/src/checkin-message.ts`.

  The rule: write for a non-technical person, in everyday words, with no tool names, ids, request ids, code or raw error text. A host-side scrubber was not added. It would rewrite the agent's words, and a pattern list can't tell "Walk ping" from a tool name.
