|---|---|---|---|
| 2026-10-04 | (TASK-809) **Per-namespace "ceiling source" (`connector` / `agent`) stored in @ax/tool-policy, written by @ax/connectors via new `tool-policy:set-ceiling-sources`.** `agent` (an OAuth MCP server) = no connector ceiling; the agent's own row decides and a tool with no row is `hold`. Setting `agent` deletes the namespace's admin defaults (the one-time cleanup; idempotent). | tool-policy evaluates `mcp.c<hex>.<tool>` with no way to reach the connector record (namespace is a hash; connectors has no global reverse lookup), and a pre-call bus round-trip to connectors would put a DB read on every MCP call. Connectors stays the source of truth for auth type and re-syncs every row at boot, so the tool-policy marker self-heals. | tool-policy asks connectors per call (rejected: hot path + no reverse lookup); per-agent mode on the copied-namespaces row (rejected: needs every agent rewritten when a connector's auth changes); "no default ⇒ allow" for OAuth only via admin rows (rejected: tools unknown at create). |
| 2026-10-04 | (TASK-809) An `agent`-sourced tool with NO override row is `hold`, not `allow`. | Removing the ceiling must not turn "nobody chose" into a grant: a tool the server adds after attach, or one attached before sign-in, still asks first. | 2026-10-04 | (TASK-809) Upsert writes `connector` entries BEFORE the commit (a throw refuses the edit) and `agent` entries AFTER it (logged on failure). | Each failure then lands on the capped side: a failed pre-write leaves the old row; a failed post-write leaves an OAuth server capped at Ask first until the next save or boot. Writing `agent` before a commit that then fails would un-cap an API-key server. | One call after commit (rejected: an OAuth→API-key edit whose call fails stays un-capped). |
| 2026-10-04 | (TASK-809) `renameNamespaces` deletes `from` markers and never moves them; `purgeNamespaces` deletes markers. | A moved marker could land on a renamed server that is now API-key and un-cap it; the upsert's own sync sets the new namespace correctly. | Move markers with the rows (rejected: loosening path). |
