# Decisions — TASK-627 (Rail: "What I learned in this chat" block)

| Date | Decision | Rationale | Alternatives |
|---|---|---|---|
| 2026-09-27 | **The feed + stream state lives in a hook (`useConversationMemory`) owned by `AgentView`, not inside `AgentRailContent`.** The block gets it as a prop; the sr-only announcer is mounted by `AgentView` too. | Below `md` the rail is a `Sheet` and `AgentRailContent` is UNMOUNTED while it is closed. The card wants the "N new" count on the rail toggle and one announcement per batch while the sheet is shut, so the stream cannot live in the unmounted tree. This is the one piece of rail state that has to be hoisted; the revoke notice stays where it is. | Keep it in the rail content (loses the count + announcement on mobile); a global store (a second owner of per-conversation state). |
| 2026-09-27 | **"Try again" is NOT offered on the save-failed state.** Copy says the retry happens on its own: "I couldn't save anything from your last few messages. Nothing's lost — I'll try again on my own in a little while." | Measured in TASK-626: there is no retry hook (declined there because a retry route must bind the conversation's own agent). The held cursor means the next pass (next turn, idle timer, chat:end) re-runs the same turns, so "I'll try again" is true and "retry now" would be a button that does nothing. Returned as a follow-up (memory:retry hook + button). | A button that only re-reads status (a lie with a click on it); building memory:retry here (a hook change + security scope, its own card). |
| 2026-09-27 | **The block shows the conversation that is ON SCREEN** (`pastDetail.conversationId` when a past one is open, else `detail.conversationId`). | "from your message" scrolls the visible transcript; a block about a different conversation than the thread beside it would point at messages that are not there. | Always the live conversation. |
| 2026-09-27 | **Relative time is shown only for rows that arrived while the block was open** ("just now", "4 min ago"). Rows from the first read show no time. | There is no recorded-at field on a statement: `when` is the instant the fact became TRUE (memory types.ts), not when it was learned. Printing it as "learned 3 days ago" would be false. The arrival time of a live batch is real. | Render `when` (wrong meaning); add a recordedAt to memory:recall (a hook-surface change for one label). |
| 2026-09-27 | **"Earlier in this chat" labels the first-read rows only when a live batch sits above them.** | With no live batch there is nothing for them to be earlier than, and the label over the only group is noise. | Always label them. |
| 2026-09-27 | **A Fix keeps the row in the block, showing the new value, via a local overlay; `MemoryFixDialog.onSaved` now passes the new id (additive).** | A Fix from the workspace writes a human row with no conversation (`agentWorkspaceCtx` has none), and closes the old one, so the next feed read drops the row entirely. Without the overlay, fixing a memory would make it vanish from "What I learned in this chat" — which reads as "Forget". The overlay lasts until reload; the Memory tab ("See all memory") is where it lives after that. | Attribute rail fixes to the conversation server-side (route change + ownership check; follow-up); let it vanish. |

Matching by `getAttribute` (not a CSS selector) means an opaque turn id never needs escaping. | Lift a `highlightTurnId` prop through AgentConversation → Message. |
