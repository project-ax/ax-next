# Decisions — TASK-878

| Date | Decision | Rationale | Alternatives |
|------|----------|-----------|--------------|
| 2026-10-05 | **Card premise partly refuted:** "it has no timeout" is false. `HookBus.call` already bounds every service call at `DEFAULT_SERVICE_TIMEOUT_MS` (120 s, `packages/core/src/hook-bus.ts`), and `proxy:close-session` registers no override. So a hung close held routing for 120 s, not forever. The card still stands: 120 s of a user's next message going nowhere is the real cost. | Read the bus code, not the card. | — |
| 2026-10-05 | **One helper, `closeProxySession(ctx, sessionId, phase)`, at all 5 call sites** (retire, connector-deleted, open-failed, runner-exit, invoke-end). It waits at most `proxyCloseTimeoutMs` (default `PROXY_CLOSE_TIMEOUT_MS` = 10 s; `Infinity` falls back to the bus bound). On timeout it logs `proxy_close_session_timeout {sessionId, phase, timeoutMs}` and resolves. It never throws. Failures log `proxy_close_session_failed` with `phase`, plus `afterTimeout: true` when the failure lands after the bound. | Only 3 sites are awaited (retire, open-failed, invoke-end). The 2 fire-and-forget sites go through the helper too, so there is one log taxonomy, and a timeout there still shows up as a log line. 10 s is generous for an in-process close (a few Map deletes) and far below 120 s. | (a) Bound only the retire site (rejected: invoke-end / open-failed also hold a turn's outcome). (b) Per-call bus timeout option (rejected: `bus.call` has none; adding one changes `@ax/core`'s surface for one caller). |
| 2026-10-05 | **The bound does not cancel the close.** The call keeps running and revokes the session when it lands. `session:terminate` follows regardless, and the `handle.exited` close is a second idempotent attempt. A test pins that a slow close still deletes the proxy table after routing moved on. | The card required "without weakening the close". | — |
| 2026-10-05 | No hook or manifest change, so no boundary review and no preset pins. Implemented inline, not via per-task subagents. | The diff is ~60 production lines in one file plus tests. | — |
