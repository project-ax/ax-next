| 2026-11-02 | Detection. A Stripe, Slack or Zendesk signature **or** timestamp header present (own property, any length) selects that app's full TASK-981 protocol. If it fails, refuse; never fall through. More than one such app present: refuse. Otherwise compute HMAC-SHA256(secret, raw body) once and compare in constant time against at most the first 100 own header entries. Skip auth/cookie and hop-by-hop names, and values over 8192. Strip one leading `sha256=`, then compare 64-char values as lowercase hex or 44-char values as padded base64. `x-hub-signature-256` is named GitHub, `linear-signature` Linear, anything else "other". SHA-256 only. | These are card decisions 2 and 3, made concrete. The equal-length rule makes `timingSafeEqual` safe to call and makes junk headers cheap. Node already caps headers at 2000 and 16 KiB. | Count only candidate headers toward the cap; normalize header-name case (the adapter already lowercases). |
| 2026-11-02 | Cross-protocol guard (planner addition).
