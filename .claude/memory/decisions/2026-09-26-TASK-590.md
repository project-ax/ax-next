# TASK-590 decisions

| Date | Decision | Rationale | Alternatives considered |
|------|----------|-----------|------------------------|
| 2026-09-26 | **Reverses TASK-523's "no task type on the embed wire" row.** The OpenRouter embed driver sends `input_type: 'search_document'` for `task: 'document'` and `'search_query'` for `task: 'query'`, explicitly for BOTH; a test pins both body shapes. | Walk TASK-589 MEASURED on kind (live OpenRouter, `google/gemini-embedding-001:nitro` @384): OpenRouter passes `input_type` through to Gemini (bogus value → Google's 400 on `task_type`; `search_document` → different vector, cosine 0.94; omitted == `search_query`, cosine 1.0). So every stored fact had been embedded as a query. Sending the query value explicitly too: relying on an omitted field's default is how the bug happened. | Send only `search_document` (query rides the default — silent if OpenRouter's default ever changes); make it configurable (YAGNI — one pinned model) |
| 2026-09-26 | **Existing vectors are re-embedded by a fingerprint GENERATION bump that feeds #752's vector-less backfill — not one or the other.** Store fingerprint becomes `<model>#<generation>`; a pre-TASK-590 store (bare model id) mismatches once, `vec0` is wiped in one transaction, and the post-record backfill re-embeds as documents. | The brief framed "fingerprint bump vs the #752 path" as alternatives. They are not: `backfillMissingVectors` selects `NOT EXISTS (… vec0 …)`, so on its own it NEVER touches a row that already has a (query-embedded) vector. Invalidation has to come from the fingerprint, which already owns "which recipe made the vectors in vec0". Cost is TASK-523's accepted transient: recall `degraded: ['semantic']` per agent until its next successful record; >200-row backlogs drain over later records. | Re-embed in place keeping old vectors meanwhile (needs a per-row recipe marker beside vec0 for a one-time migration, and leaves the dense channel comparing two recipes); a boot-time backfill (no user ctx ⇒ no credential lookup — TASK-523 rejected it for the same reason) |
