| 2026-09-29 | **Both mechanisms, not one: `@ax/routines` subscribes to `agents:deleted` (drops the agent's routine rows, default overrides and live webhook routes), AND the tick treats an `agents:resolve` `not-found` as terminal (`FireResult.agentGone` → `store.deleteAllForAgent`, no fire row, no advance).** | The subscriber stops new deletions at the moment they happen. It cannot heal the four prod orphans: their `agents:deleted` already fired (or predates the event), and it never fires again. The tick is the only place that learns an agent is gone, and it covers the subscriber failing too (HookBus.fire swallows). `agents:resolve` throws `not-found` only when `store.getById` is null (a present-but-not-yours agent is `forbidden`), and the CLI dev stub never throws it, so the signal is exact. | (a) Subscriber only: leaves existing orphans firing forever, fails done-when #3. (b) Tick prunes agents absent from `agents:list-personal-owners`: that list excludes TEAM agents by design, so it would delete every team agent's routines. (c) Parse `not-found:` out of the error string in tick.ts: couples the tick to fire.ts's message format and `conversations:*` can also say not-found. |
| 2026-09-29 | **`deleteAllForAgent` runs two plain DELETEs (overrides first, then definitions), no transaction.** | The tick calls it on its pinned advisory-lock connection; a nested transaction there is avoidable risk. Ordering makes a mid-way failure retryable: the definitions survive, so the next fire that finds the agent gone retries both. | A transaction: atomic, but not needed for two idempotent deletes. |
| 2026-09-29 | **Fire history for the deleted agent is kept; the terminal not-found fire is NOT recorded.** | Matches the store's existing rule (`routines_v1_fires` has no FK to definitions and is preserved on de-materialize). Recording one more error row for an agent no one can view adds nothing; stderr logs the prune. | Record the terminal error fire: harmless but noise. Purge fire history on delete: a separate retention question, not this card. |
| 2026-09-29 | **Implemented inline, not one subagent per task.** | ~60 production lines across 5 files in one package; the per-task dispatch overhead exceeds the work. | Subagent-driven per yolo-ship default. |
