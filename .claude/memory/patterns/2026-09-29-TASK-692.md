- **2026-09-29 (TASK-692): when a card asks for "one chokepoint" that both refuses and counts, split it into a GATE and a METER.** The gate is the veto hook every entry point shares (`chat:start`); the meter is the seam every implementation must pass to finish its unit of work (`EndTurnInput.usage`). Making the meter's field REQUIRED in the shared TypeScript interface (`TurnUsage | null`, where `null` means "cannot tell" and the host charges a flat conservative cost) is what makes "a new runner cannot skip it" true at compile time; an optional field would be skipped silently.
- **2026-09-29 (TASK-692): a veto hook that guards money must catch its own errors and refuse.** `HookBus.fire` isolates a throwing subscriber and carries on, so a naive `throw` in a `chat:start` gate fails OPEN. `admitTurn` never throws: any error becomes `reject({ reason: 'usage-check-unavailable' })`. The other direction (meters) never throws either: a metering hiccup is one error log, never a failed turn or helper call.
- **2026-09-29 (TASK-692): "unknown is never free."** Runner-reported numbers are untrusted: clamp them to bounded non-negative integers, treat a usage object with no token figure as absent, and charge a flat assumed cost when absent. Unknown models are priced at the TOP tier so they over-count. Explicit zeros are a claim, `null`/absent is not.
- **2026-09-29 (TASK-692): exact per-user limits under concurrency = one transaction under `pg_advisory_xact_lock(hashtextextended(userId, 0))`** (read sums, decide, then count). Two simultaneous messages from one user queue on the lock so both cannot read "under the cap"; different users never wait on each other. Tested by firing 20 admits at once against a cap of 5 and asserting exactly 5 pass.
- **2026-09-29 (TASK-692): rolling windows over per-minute buckets, with the window start FLOORED to the minute.** Flooring pulls in the whole straddling bucket, so the window can only over-count slightly and the limit errs strict. One indexed range query answers both the 24 h spend and the 1 h turn windows, and a calendar-day reset (burn the cap at 23:59 and again at 00:01) is avoided.
- **2026-09-29 (TASK-692): price in integers.** `10 * 0.3` is `3.0000000000000004` in floats and `Math.ceil` then adds a whole micro-dollar per call; `pricing.ts` works in hundredths of a micro-dollar per token and rounds once at the end.
