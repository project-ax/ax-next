# Patterns — TASK-545

- **A live region a component can be MOUNTED into already-full:** arm it one passive `useEffect` after mount, and on the unarmed commit render the message as a sibling immediately before the (empty, zero-height) region, then move it inside. The region is empty for a commit and a paint; nothing visibly moves. See `ActivityFeed.tsx` `armed`.
- **Commit recorders go blind to child-only updates.** The #696 parent-`useLayoutEffect` recorder only fires when the PARENT re-renders; a state update inside the child (like an arm-after-mount flag) commits without it. Record from `<Profiler onRender>` wrapped around the child instead: it fires on every commit in its subtree, after the DOM is written.
