# TASK-360 — patterns

- Deleting a file that `.claude/memory/` cites turns `scripts/__tests__/memory-cited-paths-exist.test.js` red, and R1/R2 forbid editing the citing row. The fix is to APPEND a shard line that opens with `Deleted in <TASK-ID>:` and backticks the deleted paths. The guard verifies each tombstoned path is untracked and was really deleted (not renamed away). A MOVED file is still fixed by citing its new home in a new row; do not tombstone it.
- Pick a deletion set by import-graph reachability from the entry points (`main.tsx`, `server/index.ts`), iterated to a fixed point, not from a card's list. In TASK-360 the second pass found `AgentMenu.tsx` and `lib/session-store.ts`, which the first pass had left alive through modules it deleted, and the card's list would have wrongly deleted `AttachmentChip.tsx`, which the workspace still renders.
- `git log --diff-filter=D -- <path>` reports a RENAME's old path as deleted, because the pathspec hides the new side of the pair. To mean "deleted, not moved", walk all history with `-M` and intersect.
