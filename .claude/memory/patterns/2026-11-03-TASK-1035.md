- **Every `auth:require-user` gate, mcp-oauth's included, answers only `unauthenticated` with 401 (core `isUnauthenticated`) since TASK-1035.** This supersedes the TASK-1030 patterns row's "the one gate left on a different rule is mcp-oauth's `requireUser`". mcp-oauth still logs its own `mcp_oauth_route_failed {stage:'auth', ...errFields}` 500 line rather than calling `answerRequireUserFailure`, whose `{ hook, err }` line carries the error's message — that file logs names and codes only (TASK-713), and its tests assert no fault text reaches the logger. In mcp-oauth's fake-bus tests, model "signed out" with `codedError('auth:require-user','unauthenticated')`, never a thrown `reject()`: the real bus wraps a thrown Rejection as `unknown`, so production cannot send one.
- **`useRoutineDraft` clears a refusal's message, code and field together (`clearErrors()`) on every edit and at the start of every save (TASK-1035).** A form can read `invalidField` as "the field the current refusal names". Before this, a retry kept the field: TaskForm (#1115) gated it on `errorCode !== null`, and Settings' RoutineEditor showed a stale mark.
