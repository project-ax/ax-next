# Patterns — TASK-576

- **Wiping a deployment's old memory is an OPERATOR RUNBOOK, never code** (owner ruling 2026-09-27). Runbook: `deploy/README.md` "Switching an existing deployment to facts memory". Order: switch the preset, scale the host (and git-server) to 0, erase, scale back up, so nothing re-exports stale memory mid-reset. What it erases: postgres `memory_strata_index_v2_docs` (drop) and `memory_facts_v1` (truncate); the sqlite `facts.db*` on PVC `<release>-memory-facts` (the file is deleted, the PVC is kept because it carries `helm.sh/resource-policy: keep`); the memory-exports NFS share; workspace storage.
- **Workspace storage reset differs per backend.** `git-protocol` (kind): delete the git-server StatefulSet's `repo-<release>-git-server-experimental-<n>` PVCs. `local` (GKE/production, where there is NO git-server): delete `ws-*.git` + `repo.git` on `<release>-workspace` and never the PVC itself, since it also holds `blobs/` and `skill-bundles/`.
- **The chart's default render needs no NFS.** `memory.exports` is optional and both-or-neither, and the runner's `/memory` mount exists only when it is set. Chart pod selectors are `app.kubernetes.io/name=<release>-<component>`; `app.kubernetes.io/component` is only on the controller's metadata.
