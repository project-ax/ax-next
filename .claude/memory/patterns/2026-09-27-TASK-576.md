# Patterns — TASK-576

- **Erasing workspace data from history = `workspace:purge {prefixes, keep}`** (host-only; not on the runner IPC surface; does not fire pre-apply/applied). Both git backends implement it through the shared `@ax/workspace-git-purge` (`fast-export --no-data` → byte-exact filter → `fast-import` into `refs/ax-purge/main` → verify → CAS `update-ref` → reflog expire + `gc --prune=now` → verify no unreachable objects). The temp ref is deleted LAST: it is the "compaction not yet proven" marker a crashed run is recovered from. Never force-push to the git-server instead — its repos keep `receive.denyNonFastForwards=true` on purpose.
- **A one-time destructive migration over agents needs a COHORT, not just markers.** Per-agent `done` markers make a re-run skip finished agents, but a later boot after a partial failure would otherwise re-list agents and wipe ones created AFTER the switch (and their new data). Store the agent-id list before the first destructive step and only ever process that list (`packages/memory/src/old-memory-wipe.ts`).
- **The chart's default render now needs `memory.exports.server/exportPath`** (`host.preset: memory` is the default). Chart suites carry them in each file's shared REQUIRED `--set` list; a suite that only wants the old shape sets `host.preset=k8s`. kind gets them from `kind-dev-values.yaml` (dev NFS at 10.96.200.49, `make dev-kind-memory-nfs` first).
