# Patterns — TASK-473

- **Live-region identity mutant: `key={announced}` on the region span.** It keeps the words right and remounts the node on every change — exactly the "inserted holding its message" shape jsdom cannot hear. Every node-identity assertion in `consent-announce.test.tsx` reddens on it (6/18) with pure `Object.is` failures, while text assertions stay green. Cheaper and more faithful than hand-relocating the region into a branch.
- **Passive-arrival test harness = `rerender` with new props, no click.** `armForResolution` only runs from `onClick`, so a rerender is the honest stand-in for a server push / queue read; a click-driven harness would arm focus and hide a missing voice.
