# TASK-494 — patterns worth reusing (2026-09-21)

- The shared facts contract suite lives INSIDE `runFactsContract` in
  `@ax/memory-facts-contract/src/index.ts` — backend-agnostic cases go there once and
  run under both sqlite and postgres, not in per-backend test files.
- Exporter tests need rows the product layer would never write (ownerless, foreign
  owner, no provenance). Use `engineRecord` (straight to `memory:facts:record`) for
  fixtures — and remember the personal-agent scan filters `owner_user_id`, so a
  fixture without `ownerUserId` is invisible to it.
- `remember()` derives `slot` from the relation string (`deriveSlot`); a
  'lives in'/'works at' relation lands in the profile, an unmapped one does not.
  Test profiles with mapped relations, journals with anything.
- The `workspace:applied` subscriber is a clean way to count real applies in an
  integration test — the public `workspace:apply` facade fires it post-commit.
- To force an exporter CAS retry deterministically, stub `workspace:apply` to throw
  `PluginError{code:'parent-mismatch', cause:{actualParent:'v9'}}` once then succeed —
  the retry threads `cause.actualParent` as `parentHint`, re-lists and re-reads the
  baseline pinned at that `version`, and re-scans. Never blind-overwrite.
- The version-pin field on `workspace:list`/`workspace:read` inputs is `version`
  (an opaque `WorkspaceVersion` string), not `at`.
- `expectTypeOf` alone is a vitest runtime no-op — the brand proof needs a real
  compiler pass: `execFileSync(process.execPath, [tscJs, '--noEmit',
  '--ignoreConfig', '--module','NodeNext','--moduleResolution','NodeNext',
  '--target','ES2022','--strict','--skipLibCheck','--types','node', testFile])`
  resolves workspace deps correctly when cwd is the package root and actually
  reddens on a false assertion (verified by probe).
- FS confinement must be component-wise: `realpath(hostRoot)` once, then for each
  component (agent hash, permanent, memory, facts, ...) lstat → refuse
  symlink/non-dir → mkdir the single component → realpath → assert still confined.
  Anchoring to `realpath(agentDir)` passes when agentDir itself is a symlink.
- `expect(...).resolves` needs an `await` — vitest flags the floating assertion.
