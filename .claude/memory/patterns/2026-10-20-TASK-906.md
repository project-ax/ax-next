- `2026-10-20` (TASK-906) — **An authorization rule on a tool call belongs in the service that is asked again at execute time, not only in the `tool:pre-call` gate.** The claude-sdk runner sends the execute request separately from what pre-call saw (unknown top-level keys stripped, fresh id), and a compromised sandbox controls both. Before TASK-906's carve-out, a probe on the real routines harness with Always Allow granted passed pre-call with `patch: { enabled: true }` and then executed `patch: { name: 'Pwned' }` under the same requestId: the rename landed. `@ax/routines` re-asks `decisions:authorize-routine-call` → `tool-policy:evaluate` with the input it applies, so a check inside `tool-policy:evaluate` covers both paths. The routines canary pins it with direct `tool:execute:routine_*` calls that skip pre-call.
- `2026-10-20` (TASK-906) — **A channel-web `src/lib/` module the server imports must import its siblings as relative `./x.js`, never the `@/lib/...` alias the client components use.** tsc leaves the alias unrewritten in `dist/`, so the built server fails to import it, while vitest (which resolves the alias) stays green. Check by grepping the emitted import in `dist/src/server/*.js` or `node -e "import('<abs dist path>')"`.
- `2026-10-20` (TASK-906) — **A validity rule that runs on read paths must not depend on the clock.** `validateDefinition` runs on `RoutineViewSchema`, `StoredRoutineSchema` (every `rowToRoutine`, including `claimDue` for the whole tick batch) and receipt parsing, so a rule that flips with "now" can make a saved row throw `routines:list` or the tick for everyone. The task cron floor counts 48 runs from the fixed instant 2026-01-01T00:00Z instead of from now; a `vi.useFakeTimers` test at two dates pins it.
- `2026-10-20` (TASK-906) — **When a test table pins a short-gap cron, use one whose short gap only shows at the hour boundary.** `*/16 * * * *` (:48 then :00, 12 minutes) is caught only by a floor that inspects enough runs; `*/14` is rejected by its plain 14-minute gaps, so it can't tell a 2-run floor from a 48-run one.
