## 2026-10-03 — TASK-772

- **A `document` key listener registered in a passive `useEffect` misses events in the commit→passive-flush gap when the render was triggered off a sync lane (promise continuation, fetch result).** The DOM already shows the UI; the listener isn't there yet. RTL's `findBy*` resolves off a MutationObserver inside that gap, so `fireEvent.keyDown` right after it can be lost — a CI-only flake. Use `useLayoutEffect` for listeners whose UI must work the moment it is visible. Deterministic repro: fire the event from a `MutationObserver` callback when the element appears (fails 20/20 on the passive form).
