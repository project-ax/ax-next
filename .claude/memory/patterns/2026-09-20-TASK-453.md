# TASK-453 — patterns

- **Recording props per render, generalised.** TASK-402 recorded one value and
  asserted a snapshot. Better shape: record `{renderedFor, rowScopes,
  awaitingScope}` per render and assert an INVARIANT over every frame — "on any
  render not flagged out-of-scope, every row belongs to the scope being
  rendered". A snapshot of one frame moves the moment the fetch chain grows an
  await; the invariant does not. Pair it with a non-vacuity assertion that at
  least one flagged frame happened, or the file stays green if the component
  stops rendering entirely.
- **Derive "which collection is this row from" from the FIXTURE, not from
  `event.agentId`.** The workspace-wide page legitimately contains rows whose
  `agentId` is Quill's. "Belongs to the workspace collection" and "is about
  Quill" are different facts, and conflating them makes the test vacuous. A
  `Map<rowId, scope>` built by the page factory is the ground truth.
- **A jsdom skeleton needs `role="status"` + `sr-only` text.** jsdom has no CSS
  and no pulse, so a pile of placeholder divs is indistinguishable from the
  empty state it replaced — there is nothing to assert. The accessibility tree
  is real; the animation is not.
