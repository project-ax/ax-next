# Patterns — TASK-G001 (admin-selectable models)

## Patterns (do these)

- 2026-09-30: When adding resolved-agent metadata, declare it in `AgentSchema` in `packages/agents/src/plugin.ts`; hook return validation strips undeclared fields, including `requestedModel`.
- 2026-09-30: When editing a server-resolved fallback, fetch the detail route and PATCH `model` only when the user changes it; list routes return stored rows, and re-saving a fallback destroys the owner's reversible choice. Guard the detail request with a generation invalidated on New, Cancel, and unmount.
- 2026-09-30: When adding runtime policy, audit every create path as well as validation and resolution. The personal-agent bootstrap in `packages/channel-web/src/server/routes-agent-bootstrap.ts` supplies a model explicitly, so it must consume the Default too.
- 2026-09-30: When discovering provider capabilities, iterate core `PROVIDER_ENDPOINTS` and gate each hook with `bus.hasService`; providers own credential resolution and fixed HTTP destinations.
- 2026-09-30: When caching credential-dependent responses, partition by authenticated identity and keep last-good data separate from the latest status. An observed `no-key` must invalidate good state; an observed failure must not quietly become `live` after a retry window.
- 2026-09-30: When bounding provider JSON, enforce the byte cap during streaming, share pagination deadlines and byte budgets, and refuse redirects; checking size after `response.json()` cannot bound memory or network reach.

## Anti-Patterns (don't do these)

- 2026-09-30: Do not publish an awaited storage read over a newer successful save. A save mutex alone does not protect read-cache publication; use a generation guard or shared serialization.
