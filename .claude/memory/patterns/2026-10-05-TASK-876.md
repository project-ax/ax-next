- `2026-10-05` (TASK-876) — **`vi.useFakeTimers` does NOT control `socket.setTimeout`.** Net/TLS socket idle timeouts run on Node's internal timer list, not on `globalThis.setTimeout`. Measured: with `toFake: ['setTimeout','clearTimeout']`, `advanceTimersByTime(1000)` left a 100ms `socket.setTimeout` unfired, and it later fired on the real clock. So TASK-865's fake-clock pattern does not work for idle timeouts. Use this instead: `vi.spyOn(TLSSocket.prototype, 'setTimeout')` and hold every call whose `ms` equals the test's idle value. Assert how many were held, so the test cannot pass vacuously. Then, once the precondition is observed (e.g. the upstream holds the request), arm them for real with `realSetTimeout.call(sock, ms, cb)`. See `deferIdleTimers` in credential-proxy `listener-provider-metering.test.ts`.
