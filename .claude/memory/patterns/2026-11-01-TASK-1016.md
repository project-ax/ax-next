- **Node `http`: `'finish'` fires even when the socket write behind `res.end(chunk)` failed, and with the socket destroyed but `res.destroyed` still false, `res.write(chunk, cb)` never calls `cb` and `end()` never fires `'finish'`.** To know a sized body's last bytes reached the OS, write them with `res.write(last, cb)` (cb error → client gone), always pair the wait with a `'close'` listener, then `end()`. `@ax/http-server`'s `awaitClient` (TASK-1016) does this; `body-stream.test.ts` pins both halves.
- **Asserting a timer was cleared:** a "kept-alive socket still works after the window" test cannot see a leaked timer whose callback only settles an already-settled promise. Spy `globalThis.setTimeout`/`clearTimeout`, record handles armed with the window's delay, and assert every one was cleared (TASK-1016).
- **Worktree-isolated agents: a Bash command that runs a tool with a `$var` operand (`sed -i '' … $f`, `for p in …; pnpm --filter @ax/$p`, `export X=$HOME/…`) is refused as unverifiable.** Spell the path or list out literally (`pnpm -r --filter A --filter B run test`, `DOCKER_HOST=unix:///Users/<u>/.orbstack/run/docker.sock cmd`).
