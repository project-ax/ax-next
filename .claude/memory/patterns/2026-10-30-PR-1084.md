# PR-1084: invalid outline on Input/Textarea (patterns)

- **Tailwind 3 has no `aria-invalid:` variant, and it builds no CSS for one without any warning.** channel-web is on Tailwind 3.4. Write `aria-[invalid=true]:`. The bare form (shadcn v4 snippets use it) passes every jsdom test, because jsdom has no stylesheet and the class is present on the element. To be sure a variant works, grep the built CSS (`pnpm build`, then `dist-web/assets/*.css`). `components/ui/__tests__/invalid-outline.test.tsx` fails if any source file uses the bare form.
- **Before making a primitive draw a state, audit every site that sets it.** Search for `aria-invalid` and check when each site turns true. A site that marks an empty field invalid on first render goes from a red label to a red box. Usage prices' new-model field was the one case.
