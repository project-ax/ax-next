# Patterns — TASK-535

- **Opting out of shadcn `Alert`'s live role:** `role={undefined}` works because `alert.tsx` spreads `{...props}` AFTER `role="alert"`. Use it when a shared live region is the card's voice, so the visible box stays a focus target without becoming a second (and on-mount) announcer.
- **Disclosure-toggle mutant for live regions:** a note that depends on `expanded` passes every stale/notice arrival case in one state and re-announces on each toggle. Pin it with a rerender sequence collapsed→expanded→collapsed asserting the region text never changes.
