# PR-1079 — minimal New / Edit task dialog (patterns)

- **Radix `<SelectItem value="">` throws.** It's unconditional: "A <Select.Item /> must have a value prop that is not an empty string". When an "extra" item is built from a saved or typed value (an unlisted interval), guard it with a real parse (`durationToSeconds(v) !== null`). Otherwise clearing a field and opening the Select unmounts the form, and the ErrorBoundary loses the draft.
- **A validation issue whose control isn't rendered is a silent no-op Save.** The focus-first-invalid effect finds nothing, and there's no FieldError to draw. Either keep a field rendered while it has a shown issue, or route issues for unmounted controls to a form-level, focusable alert. The same goes for host refusals that name a field inside a collapsed section: open the section, then focus.
- **Placeholder-only fields need visually hidden `FieldLabel`s.** The shared `Input`/`Textarea` primitives don't style `aria-invalid` (only `InputGroup` does), so a task-only form takes its outline from the Field's `data-invalid` (`group-data-[invalid=true]/field:border-destructive`). Restyling the primitives would change about 14 other screens that set `aria-invalid` while you type.
- **Splitting a shared editor:** `use-routine-draft.ts` holds RoutineForm's state, validation and save logic, and `RoutineEditor` renders `TaskForm` only in `taskMode`. Prove the non-task path is unchanged by diffing the old logic block against the hook mechanically, and leave the non-task tests untouched.
- **Presets must never silently rewrite a saved schedule.** A controlled Radix Select doesn't fire `onValueChange` when the same value is re-picked. Show a preset-equal cron as that preset, keep anything else as its own "custom" item, and write only when a different preset is picked.
- **A "kept" assertion can go vacuous after a UI move.** One test queried a switch while a different popover was open, so the switch's container was never mounted. Mutation-test moved assertions: deliberately break the behaviour and confirm the test fails.
