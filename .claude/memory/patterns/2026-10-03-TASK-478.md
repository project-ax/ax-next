## 2026-10-03 — TASK-478

- **The passive-useEffect focus/listener race only exists on NON-discrete renders.** React 19 flushes passive effects synchronously at the end of a SyncLane commit (click, keydown), so a component opened by a click is already focused / listening by the time a MutationObserver microtask can see it — measured with a real `el.click()` and `IS_REACT_ACT_ENVIRONMENT=false`. A MutationObserver probe driven by `fireEvent.click` therefore PASSES on the old code (vacuous). To prove the race, mount the component from a promise continuation (`useEffect(() => { void Promise.resolve().then(() => setOpen(true)) }, [])`) inside `render()` + `waitFor` — red every run on the passive form, green on `useLayoutEffect`. Before calling a site "live", check whether any of its mount triggers is non-discrete (fetch result, promise, timer); if none is, say "latent".
