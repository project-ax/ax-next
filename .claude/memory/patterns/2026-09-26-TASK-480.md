# Patterns — TASK-480

- **The learned-memory doc `name` is now fenced** (`routes-workspace.ts` `readMemory`,
  `fenceLine(d.name, FILE_LABEL_MAX_CHARS) ?? LEARNED_DOC_FALLBACK_NAME`). The
  2026-09-20-TASK-436 patterns shard says it "is still unfenced". That was true
  when it was written and is not true now. The grep hint the shard gives
  (`scope: 'learned'`) is still correct.
- **Trace a value to where it is WRITTEN before you call it "model output".** TASK-480's
  card (and a comment it cited) called the learned doc name raw model output. It is
  three hardcoded strings in `@ax/memory-strata` `readLearnedDocs`. Only the `body` is
  model output. The fence was still worth shipping as a boundary fence, but the
  severity argument was built on the wrong source. Reading one function would have
  shown that.
