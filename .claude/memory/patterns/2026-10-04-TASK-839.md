# TASK-839 patterns (2026-10-04)

- **MCP SDK: `Client.close()` rejects EVERY pending request on it** with `McpError -32000 "Connection closed"`. When you replace a connection mid-session, do not close the old one while other calls are still running on it. Count in-flight calls, mark the old one retired, and let the last call out close it.
- **Session-loss tests:** `packages/agent-aisdk-runner/src/__tests__/helpers/mcp-test-server.ts` now has a `sessionful` mode with `forgetSessions()` (it answers 404/-32001, just like the SDK server), `seenMethods` (count `initialize`s) and `intercept(method)`, which can hold, refuse or override any POST. These cover reconnect, race and drain cases without mocking the SDK.
