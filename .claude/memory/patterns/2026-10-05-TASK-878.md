- `2026-10-05` (TASK-878) — **With `vi.useFakeTimers({ toFake: [...] })`, call `vi.spyOn(globalThis, 'setTimeout')` AFTER `useFakeTimers`, not before.** If you spy first, `useFakeTimers` replaces the global, the spy wraps the real timer, and the spy never sees the code's call. Restore in reverse order: `spy.mockRestore()`, then `vi.useRealTimers()`.
- `2026-10-05` (TASK-878) — **Holding routing in a keepalive test drops the pre-fired turn-end.** The helpers `fireTurnEnd` in keepalive.test.ts fire `chat:turn-end` on `setImmediate` before `agent:invoke` registers its waiter. That only works because routing normally settles in microtasks. If a test holds routing (for example on a hung service), that turn-end is lost, so fire another one for the fresh session once the spawn has happened.
