## Patterns

- `2026-09-26` (TASK-472) — **A doc-scanning guard fed only the real docs cannot test its own exemption.** The real docs are correct, so any exemption rule that happens to agree with them passes. `board-task-id-race.test.js`'s wiring test stayed GREEN when its exemption went back to the fail-open shape rule. The fix: turn the scanner into pure functions (`bashFences`, `scanFence`, `allocatorCalls`, `wiringProblems`), have the real-docs test call exactly those, and feed them a table of hostile synthetic docs. Each row embeds two known-good fences so the vacuity floor is satisfied and the row isolates one fence. Pin the row count in a test too, so a mutant that deletes rows cannot pass by shrinking the table. Measured result: the old-shape mutant goes 8 red out of 38, the same 8 predicted before the run.
