- **2026-10-03 (TASK-758): when a side effect in ANOTHER plugin must succeed for an edit to be safe, gate it with a service call BEFORE the commit — not a subscriber event.** `HookBus.fire` isolates subscriber throws (logs `hook_subscriber_failed`, continues, returns not-rejected), so the firer cannot tell "landed" from "failed". Pattern: `if (bus.hasService(H)) { try { await bus.call(H, …) } catch { throw PluginError(<domain code>) } }` → then write. Declare `H` in `optionalCalls` (absent ⇒ nothing to protect). Instance: `connectors:upsert` → `tool-policy:reset-tool-namespaces` (kept-name endpoint change), route maps `tool-permissions-reset-failed` → 503.
