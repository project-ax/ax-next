  - **Two "findings" from that walk were driver artifacts, not product bugs** — worth recording because both looked convincing. A duplicated attachment chip (the payload really did carry two `attachment` blocks) and a `removeChild` console error were BOTH caused by mixing Playwright's `chooser.setFiles()` with the MCP's `browser_file_upload` — the MCP intercepts the file chooser, so both handlers fired and the file uploaded twice.
